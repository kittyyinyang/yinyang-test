## 一、战略判断

**胜负手不是「测试」，而是「关系语言」**：MBTI 的战场是"我是谁"（已饱和疲劳）；阴阳人格的天然战场是"我们怎么回事"（情侣/夫妻/闺蜜/母女）。配对互补是 MBTI 没有的原生武器——**配对是增长引擎，测试只是入口**。

- 时机：MBTI 疲劳期 + 国风审美强势 = 本土人格框架真空窗口；
- 定位句（建议做成站内标准答案卡）：「MBTI 告诉你 16 种性格，阴阳人格告诉你关系里只有两种能量」；
- 优势：阴阳是无需教育的母语概念 ｜ 四型好记 ｜ 配对逻辑内置 ｜ 197 知识点是内容护城河；
- 认知风险：阴阳≠算命——坚持"能量"口径 + 晨昼意象（已做对）。

## 二、漏斗诊断

```
获客 → 测评 → 结果 → 分享 → TA测试 → 配对报告 → 复访/深学
 ✅规划  ✅叙事化  ✅七区   ⚠️最弱    ⚠️附属功能   ⚠️钩子弱
```

1. 分享靠复制文字链接——微信里链接打开率低、github.io 信任度低，**人们分享的是截图**；
2. 配对是结果页附属，应升级为核心仪式；
3. 零埋点零数据，盲飞。

## 三、优先级建议

### P0（上线推广前必做）
1. **结果页 canvas 分享图片卡**：印章+能量条+金句+slogan+链接，PNG 长按保存/发朋友圈；
2. **配对流程产品化**：「生成 TA 的专属邀请」→ 带参测试 → 双人合盘报告页（双印对望+互补建议+二次转发钩子）；
3. **最简埋点**：开始测/完成/分享点击三事件，免费统计即可。

### P1（上线两周内）
4. 影视 IP 四型速查与站内打通（视频结尾导流→落地型格卡组）；
5. 复测对比视图（"70%→62%，你在走向平衡"——复测文化=回归引擎）；
6. 首页每日一问轮换。

### P2（有数据后）
7. 自定义域名 + 每卡独立页面（hash 路由 SEO 不友好，197 卡=197 个 SEO 入口）；
8. 快速版 10 题 / 完整版 20 题分流；
9. UGC 组合故事征集。

## 四、增长引擎（冷启动）

- 种子池：B站 UP主现成受众 + 双生/成长社群；
- 内容飞轮：影视四型解读（小红书/抖音获客）→ 测试（转化）→ 配对图片卡（裂变）→ 问一问（留存）；
- 术语运营：把"承重者/破局者/连接者/深潜者"运营成"i人/e人"级口头禅，slogan 金句做传播物料。
