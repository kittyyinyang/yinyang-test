## §3 首席流量官视角（增长与裂变）

### 3.1 裂变闭环已跑通 ✅

```
分享图（长按保存/朋友圈）
   ↓ 右下角 QR + 品牌行
扫码进站（?from=share&t=type / ?kp=qaId）
   ↓ URL 参数路由
落地结果页 / 知识卡
   ↓ 再次生成分享图
二次分享（裂变）
```

- 结果图链接：`?from=share&t=<type>` → 新用户直达对应型格结果页；
- 知识卡链接：`?from=share&kp=<qaId>` → 直达单卡（问一问/搜一搜共用数据层）；
- 分享图底部统一行动区：「品牌行 + 长按识别引导 + 220px QR 白卡」——这是微信里唯一不依赖链接信任度的入口。

### 3.2 增长钩子盘点

| 钩子 | 现状 | 判断 |
|---|---|---|
| 影视 IP 解读（哪吒/甄嬛传） | 内容侧推进中 | ✅ 与四型人格卡组联动 |
| 配对裂变 | 未产品化 | ⚠️ P0 待排期（关系语言是主战场） |
| 反馈问卷 → 用户访谈 | 已上线 | ✅ 8 题 + 4 道内测知识题 |
| 体系化分发 | 规划文档已出 | ✅ docs/知识切片_体系化与分发规划_v1 |
| 埋点数据 | 无 | ❌ 盲飞，建议最快补 3 事件埋点 |

### 3.3 冷启动风险提示

- **github.io 信任度低**（微信内打开率低）——当前靠「图片卡 + 二维码」绕开，中期建议自定义域名；
- 单一内容源（B站 UP主）—— 知识体系 140 卡正在长成自有资产，需加快「双生捞回 + 场景专题包」；
- 术语「承重者/破局者/连接者/深潜者」建议运营成 i人/e人 级口头禅，做传播物料。
