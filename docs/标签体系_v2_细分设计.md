## 二、五轴标签体系（v2）

| 轴 | 字段 | 取值 | 来源 |
|---|---|---|---|
| 1 合集溯源 | `collection[]` | 13 个合集（双生火焰/小课堂/成长蜕变…） | 原标签 `#合集·` 前缀，仅溯源**不参与归类**（目录为准） |
| 2 主题域 | `domain` | 九域单选（见下） | **由目录（module→subGroup）判定**，合集冲突时以目录为准 |
| 3 细分概念 | `tags[]` | 178 个规范标签（归一+细分后） | 同义词归一表（~60 组）+ 子组默认标签注入 + 标题关键词细分规则（~30 条） |
| 4 受众型 | `types[]` | yang-male / yang-female / yin-female / yin-male | 标题+标签关键词映射，供「为你推荐」 |
| 5 场景 | `scenes[]` | love / work / family / self | 标题+标签关键词推断，供结果页场景深链 |
| 附 | `rawTags[]` | 原始标签全文 | **只增不删**：原始信息永不丢失 |
| 附 | `advanced` | true/false | 目录为准：双生关系篇整篇 + 深水词（九楼/超灵/累世/魔考/灌顶/切断/高桌/元神/佛魔…） |

### 主题域：两大块 × 二级课题（用户拍板结构，D8/D9 已取消）

```
阴阳人格（245 条）
  ├─ 能量本质        28   阴阳定义/判断/平衡/具身化/特质
  ├─ 四型人格       143   四型子组全部（男阳/女阳/女阴/男阴/综述）
  └─ 关系互动        74   双生关系篇 + 三方/配对/亲密互动类

自我成长（296 条）—— 按课题分类
  ├─ 觉察与信念      70   觉察方法/自我认知/潜意识意识化/信念规训/投射（含学习方法、运营随笔融入）
  ├─ 情绪与边界      18   情绪处理/情绪表达/边界/恐惧防御/冲突
  ├─ 爱自己与自我价值 36   爱自己/自恋与自信/不配得/接纳评判/人格与自我/面具
  ├─ 情感关系        27   亲密关系子组 + 付出讨好/试探信任/沟通表达等关系课题
  ├─ 亲子教育        40   原生家庭/亲子教育/人格成长
  ├─ 灵性觉醒        82   链接高我/生命意义/业力因果/灵魂/道/佛魔/合一（含灵性随笔融入）
  └─ 实修与疗愈      23   实修案例/疗愈渡人/创伤疗愈
```

- 数据字段：每条带 `block`（阴阳人格/自我成长）+ `domain`（二级课题）两个独立字段，前端可先按大块分组、再按课题筛选；
- 归类纪律：**目录优先**（篇/子组直接定域），标签只用于「自我成长」内部课题细分；D8 剧情纪事删除（少数剧情条目按内容归入关系互动/觉察信念）；D9 杂谈随笔已融入（学习方法/运营随笔→觉察与信念，灵性随笔→灵性觉醒）。

## 四、与网站各处的接入

1. **搜一搜**：消费 `CORPUS_REFINED`（变量名在装配进 `data_corpus.js` 时对齐为 `CORPUS_DATA`），一级召回问答卡、二级召回本索引；`advanced` 条目显示朱砂「进阶」徽标；`TAG_FREQ` 驱动「热门标签」筛选器；
2. **问一问「为你推荐」**：`types[]` + `scenes[]` 过滤；
3. **结果页场景深链**：`scenes[]`（work/love/family）关联场景问答卡组；
4. **玄学紫圈**：数据层即无此内容（非前端隐藏），彻底不进搜索。

## 五、维护方式

- 改标签规则/加同义词 → 只改 `scripts/build_corpus_refined.py` 重跑（数据文件自动重生成）；
- 新增语料（B716+）→ 把索引行加进语料全量版-最新.md 的索引区，重跑脚本即可；
- 长尾标签（105 个出现 1–2 次）保留在 rawTags 供搜索兜底，不进标签云；后续可人工评审升格。
