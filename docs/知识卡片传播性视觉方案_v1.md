## 一、传播性设计原则（5 条）

知识卡传播的本质：**一张卡 = 一次截图 = 一张海报**。用户在微信/朋友圈看到的是「静态首屏」，不是可交互页面。所有设计围绕「截图后 3 秒内让人想转发」展开。

### 1. 截图即海报：首屏即完整叙事
`.qcard` 折叠态必须独立成立——分类章 + 问题 + 摘要 + 要点已经构成完整海报，佐证/镜子/金句是「展开的赠品」。设计原则：**不展开也有分享价值，展开后更值得分享**。
> 截图后的样子：白底卡片，顶部一行徽章，正中一条大字问题，下面 3~5 条带序号要点，四角有品牌印记——像一张小海报。

### 2. 一卡一记忆点
每张卡只强化一个视觉焦点，不堆叠：
- 四型卡 → 焦点是「画像 + 型名印」= 人格名片；
- 金句强的卡 → 焦点是「金句大字」= 金句卡；
- 配对卡 → 焦点是「双印对望」。
**禁止**一屏同时出现画像横幅 + 大金句 + 场景插画三层焦点。

### 3. 四型卡 = 人格名片
纵探卡天然带 `forTypes`（如 `yang-female`），`TYPE_IMG[type]` 可直接命中对应画像（女阳→`images/female-yang.jpg`）。四型卡截图出去自带「身份标签」——看到的人第一反应是「我是不是也这样」，这是天然的好奇心钩子。设计：**凡是 `forTypes` 命中的卡，一律复用 TYPE_IMG 做身份锚点**。

### 4. 印章即品牌水印
分享图/金句卡/四型卡上必须出现 1 枚印章（朱砂=阳、黛蓝=阴、墨=通用）。印章是「阴阳人格出品」的视觉签名，也是防搬运的品牌资产。用户截图转发时，印章随图扩散 = 品牌被动获客。

### 5. 克制即高级
东方哲思感 ≠ 幼稚。emoji 只用于**情绪识别**（💗情感/💼职场/🏠家庭/🌙独处），不用于装饰性插画；所有「图腾/意象」优先用**单字印章 + 几何线条**表达，不画卡通。装饰密度上限：每屏 1 个主装饰 + 1 个水印。

## 二、四型人格卡配图方案

### 2.1 现状与资源盘点

| 资源 | 现状 | 位置 |
|---|---|---|
| 画像图（4 张 jpg） | 结果页 `.r-banner` 已用，118px 圆角头像 + 印章叠放 | `TYPE_IMG`（L1835）；渲染于 `renderResultInto` L2828-2831 |
| 画像卡（4 张总纲） | `q-kp-b1-01`~`q-kp-b4-01`，kpId 为 `kp-bX-XXXX` | `qa_core4.js:277` 等 |

| 主题表 | `DEEP_THEME` a=形成 … j=识别信号 | `index.html:2771` |

### 2.2 kpId 主题 → 视觉元素映射表

纵探卡每张取「1 个主题字（印章）+ 1 个几何意象（内联 SVG/CSS）+ 1 个情绪 emoji（可省）」。主题字用于卡头小印与分享图，几何意象用于展开横幅与分享图氛围。

## 三、全卡类「卡片传播协议」

定义一套**五段式传播节奏**，任何分类的卡都遵守同构，但按分类换「皮肤」（见第五章）：

```
[卡头] 分类印章 · 核心/序号 · 场景色块      ← 身份与来源
[问题] 18px 衬线大字（首屏唯一主焦点）       ← 钩子
[摘要] 14px 次级文字                        ← 说清是什么
[要点] 阴阳双色序号章列表                    ← 论证含金量
[展开] 佐证 → 镜子 → 金句大字收尾            ← 深度 + 传播赠品
```

## 四、分享图升级（canvas 1080×1700）

现状 `makeCardImage`（L1549）：纸白底 → 晨昏微渐变 → 小印「阴阳」→ 标签行 → 问题 → 简答 → 金句 → 底部 QR。问题：**无画像、无主题、无氛围、四型卡与普通卡长得一样**。

canvas 绘制约束：**不能用内联 SVG 复杂插画，但可以** ① `ctx.drawImage` 画位图（画像 jpg）② 渐变/圆/弧/线 ③ `ctx.fillText` 画 emoji 与文字 ④ 现有 `_cxSeal` / `_cxWheel` 复用。所有方案都在这四类能力内。

```js

  try{
    var R=150, cx=W/2, cy=430;          // 主视觉区：画像圆角头像
    ctx.save(); _cxRound(ctx,cx-R,cy-R,R*2,R*2,28); ctx.clip();
    // cover 裁切：取短边裁中间
    var s=Math.min(img.width,img.height), sx=(img.width-s)/2, sy=(img.height-s)/2;
    ctx.drawImage(img,sx,sy,s,s,cx-R,cy-R,R*2,R*2);
    ctx.restore();
    // 描边 + 主题字大印叠右下
    ctx.strokeStyle='rgba(212,165,116,.55)'; ctx.lineWidth=3; _cxRound(ctx,cx-R,cy-R,R*2,R*2,28); ctx.stroke();
    _cxSeal(ctx,cx+R-10,cy+R-10,84,themeChar||'型', tSeal&&tSeal[0]==='阳');
  }catch(e){}
};
img.src=tImg;   // 失败时静默：分享图仍可出，只是无画像
```
- **布局调整**：画像占据 y≈280–580 主视觉区，问题下移到 y≈640 起；简答、金句、QR 区随之下移（沿用现有流式 y 变量即可，改 3 个初始值）。

> 截图后的样子：顶部按主题氛围色渐变，中央是那人的大圆角画像，右下角叠一枚主题字印（源/悖/局/…），画像下方才是大字问题——一眼看出「这是谁的哪一张卡」。

## 五、按分类的策略差异

统一遵守第三章的传播协议，各分类换「皮肤 + 构图焦点」。

### ⭐ 核心知识（总纲型：讲透一个维度）
- 皮肤：朱砂印章「核」+ 晨昏双色渐变顶（阳/阴同在，表总纲）。
- 构图焦点：**问题大字**。问题 = 总纲命题（如「为什么你总在关系里反复内耗」），放大到 20px，摘要变短。
- 要点色：一律琥珀（中性），不偏不倚。
- 分享图：顶部晨昏轮 `_cxWheel` 微缩作装饰 + 双色能量条元素（复用 `makeShareImage` 的 ⑥ 阴阳占比条逻辑）。
> 截图后的样子：一张「总纲海报」——上晨昏轮、中问题大字、下阴阳占比条，朱砂「核」印，品牌感最强的一张。

### 阴阳能量（对立维度型）
- 皮肤：单极色。卡 `polarity=yang` 全卡橙调、`yin` 全卡蓝调（`both` 中性琥珀）。
- 构图焦点：**阴阳对照**。insight 第一条标「阳 =」、第二条标「阴 =」，要点章前加小极标记 ☀/☾（或「阳/阴」单字）。
- 分享图：氛围渐变取单极色，中央可放 `_cxSeal` 单字大印（阳/阴）替代画像。
> 截图后的样子：一张橙色卡「阳的一切」vs 蓝色卡「阴的一切」，刷屏时形成色块序列，视觉上就讲了「阴阳」。

### 四型人格（名片型）
- 皮肤：画像缩略 + 型印（承/破/连/潜）+ 主题字印。
- 构图焦点：**画像 + 型名**。卡头 = 小名片（画像+印），展开横幅 = 主题专题（见 2.3 落点 B）。
- 分享图：按 4.1 画像主角构图。
> 截图后的样子：一张「人格名片」——画像、型印、主题章、一句话，转发文案自动变「我就是/我身边有这种型」。

### 关系与配对（双人型）
- 皮肤：双印对望。卡头分类章直接做成「两枚 10px 微印 + S 连线」（复用 `.pair-avatars` 的 data-uri S 线 L391-393）。
- 构图焦点：**对望构图**。若卡带配对语义（`scene:['love']` + 内容讲互动），展开横幅顶部放「双印对望」小图。
- 分享图：中央是**两枚大印左右对望** + 中间 S 细线（canvas：两个 `_cxSeal` + 一条 `quadraticCurveTo`），配对 tag 大字居中。
> 截图后的样子：一张「合盘卡」——两枚印隔着 S 线对望，像一份婚书。

### 成长课题（路径型）
- 皮肤：墨色印章「修」+ 台阶线底纹（CSS 重复线性渐变可画四级台阶）。
- 构图焦点：**路径意象**。insight 天然是「觉察→创伤→信念→修法」的序列，序号章改「01→02→03」阶梯式排列（`insight-item` 左侧竖线改成递增高度）。
- 分享图：底部画 4 级台阶（canvas 画 4 条递减宽度的矩形），台阶顶端放一枚「修」印。
> 截图后的样子：一张「修行路径卡」——问题在最上，四级台阶一级一级通向一枚墨印，天然有「下一步做什么」的行动暗示。

### 风险与注意事项

1. **canvas 中文/emoji 兼容**：`ctx.fillText` 画 emoji（💗💼）在部分安卓 WebView 会掉字，方案中的场景信息在分享图里用文字（情感/职场）而非 emoji——保持现状做法。
2. **图像跨域**：`TYPE_IMG` 是本地 jpg，无跨域问题；但 `drawImage` 需 `img.crossOrigin` 无需设置（同源）。若未来图放 CDN，需在 `new Image()` 前设 `img.crossOrigin='anonymous'`。
3. **性能**：每张纵探卡加载同一画像，浏览器会缓存，无网络开销；首屏 40 张卡同时渲染时 `loading="lazy"` 可降首屏压力。
4. **回归面**：P1 改动集中在 `qaCardHtml`/`makeCardImage` 两个函数，回归点 = 问一问/搜一搜/结果页深潜/分享图四类视图的截图对比。
5. **不做的事**：不改数据 schema、不加数据文件、不引入外部字体/图片——全部在 `index.html` 内完成。

## 附：一句话总结

最高传播力的设计点有两个：**① 四型卡「画像+主题章」的人格名片化**（复用现成 `TYPE_IMG`，零素材成本，截图自带身份钩子）；**② 金句可独立成图**（正方形金句卡，天然适配朋友圈）。最高价值落地点是 **P0 的「分类印章 + 四型卡头缩略图」**——只加 60 行 CSS 和两处模板串，全站知识卡首屏立刻从「文字列表」变成「可截图的海报墙」。
