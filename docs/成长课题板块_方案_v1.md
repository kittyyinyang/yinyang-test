# 「成长课题」板块 · 方案 v1

> 定位：把「个人成长 / 疗愈 / 练习」内容从阴阳人格理论中单独区分出来。
> 测一测、问一问回答 **「你是谁」**；觉察疗愈回答 **「怎么修」**——从知道，到做到。
> 数据全部复用现有语料库，零新增数据文件。

---

## 一、为什么单列一个板块

| | 阴阳人格（现有板块） | 成长课题（新板块） |
|---|---|---|
| 回答的问题 | 我是哪种能量内核 | 我怎么和它相处、怎么长 |
| 内容形态 | 理论、判定、配对 | 方法线、练习、案例 |
| 用户心智 | 认识自己 | 自我和解 |
| 现有素材 | 四型人格 123 卡 | **成长课题 48 卡 + 工具箱 4 卡 + 实战觉察 20+ 卡** |

现状问题：48 张成长课题卡和 20+ 张实战觉察卡散落在问一问/搜一搜里，和理论卡混在一起，用户**不知道从哪下手、不知道先后顺序**。单列板块后，成长内容有自己的动线：方法线 → 每日练习 → 课题库 → 实战案例。

## 三、关键交互设计

1. **入口**：底部导航加第 6 个 tab「觉察」（icon：🌱）；同时首页加一个入口卡片（成长课题 48 卡 + 每日练习）。6 tab 用 icon + 2~3 字短词，移动端一行排得下。
2. **方法线**：三台阶竖向排布，每台阶「标题 + 一句原文引语 + 去看卡」，末尾一个公式条（复用工具箱卡 quote）。
3. **每日练习**：按日期轮换（`dateNum() % 池长`），卡片式「练习主题 + 具体动作 + 镜子问题」，每天不同，形成回访钩子。
4. **课题库**：按「阴的课题 / 阳的课题 / 平衡总纲」分组，组内卡带已读标记（复用 markQaRead），进度可视化。
5. **实战觉察**：chips 筛选 + 卡列表，点击 `goQaCard()` 直达完整知识卡（有 B 站时间戳佐证，可回看原文）。
6. **与结果页联动**：结果页 ④ 深入学习区顶部加一行「你的成长课题」——阳型推「修坤德三件套 y5-11 + 示弱表达承接」，阴型推「y5-12 立边界 / y5-03 自我接纳」，配「去觉察疗愈 →」按钮（带 `?t=type` 可定制推荐）。
