## 1. 知识切片体系化（3 个层级）

### 1.1 原子卡（已建）
- 形式：单问 + 单答 + 1–2 句金句 + B站时间戳原话
- 数量：核心 ~80 张 / 扩展 ~400 张（corpus 500+ 句）
- 字段：`qaId / kpId / stage / category / scene / polarity / forTypes / link / quote / evidence[]`
- 「polarity」新增：阳（y1/y3-b1/y3-b2）/ 阴（y2/y3-b3/y3-b4）/ 共通（y0/y3-通用/y4/y5/kp-*）

### 1.2 切片包（待建）
将 3–7 张原子卡按"用户场景"组装成中颗粒切片，可独立分享 / 二创：

| 切片包名 | 卡片数 | 主推 Tab | 适用场景 |
|---|---:|---|---|
| 「阳的孤独」 | 5 | 阳 | 阳型（特别是男阳）测完后的深度共情 |
| 「阴的误解」 | 5 | 阴 | 阴型（特别是女阴）抗标签 |
| 「配对暗号」 | 6 | 共通 | 情侣 / 闺蜜 / 同事配对（4×4 = 16 型配对全集） |
| 「亲子诊断」 | 4 | 共通 | 家长判断孩子倾向 + 应对策略 |
| 「职场破局」 | 5 | 阳+共通 | 阳型职场瓶颈 / 阴型破局 |
| 「自我和解」 | 5 | 阴+共通 | 阴型边界 / 阳型放松 |
| 「哪吒读法」 | 4 | 阳+阴 | 哪吒四视角拆解（拉新首选） |
| 「甄嬛传」 | 4 | 阴 | 甄嬛（女阴）/ 皇后（女阳）/ 华妃（女阳）等 |
| 「热梗解读」 | 3+ | 阳 | 紧跟当月热点（每月更新） |

### 1.3 主题专栏（待建）
将多个切片包按"主题"串成"专栏"，可做"周更内容"：

- **专栏 A · 阳的觉醒**（4 周）— 给阳型的共情与卸载
- **专栏 B · 阴的破局**（4 周）— 给阴型的边界与行动
- **专栏 C · 关系的阴阳**（3 周）— 配对 / 家庭 / 职场
- **专栏 D · 影视四视角**（持续）— 用阴阳视角解读《哪吒》《甄嬛传》《长安三万里》《年会不能停！》等

## 2. 标签脑图联动（已建 tag_graph.js）

### 2.1 当前结构
4 根（人格内核 / 关系与配对 / 自我成长 / 应用场景）→ 50 叶子

### 2.2 与知识切片的映射

- 加「难度」维度（stage 0–5）
- 用户从脑图节点点击 → 自动进入对应 Tab + 标签筛选的列表

## 3. 分发渠道规划

### 3.1 站内裂变（已建，本轮补全）

| 渠道 | 工具 | 闭环 |
|---|---|---|
| 结果分享图 | 1080×1700 PNG + QR | 扫码进站 → `?from=share&t=type` → 测同款 / 看深度解读 |
| 知识卡分享图 | 同上 + `?from=share&kp=qaId` | 扫码直达该卡片 |
| 配对邀请图 | `invite=true` 变体 | 朋友扫码 → "我也在等你" → 测 → 出合盘 |

### 3.2 站外内容（待规划）

| 渠道 | 形式 | 频次 | 切片来源 | 工具链 |
|---|---|---|---|---|
| 小红书 | 9 图 + 长文 | 每周 3 | 影视四视角 / 切片包 | 剪映模板 + 醒图 / PS |
| 抖音 | 60s 竖屏 | 每周 3 | 切片包 / 内测知识题（互动） | 剪映 + 数字人 / 口播 |
| 视频号 | 短视频 | 每周 2 | 哪吒 / 甄嬛传 | 剪映 + B站素材切片 |
| 公众号 | 长文（1500–3000字） | 双周 | 专栏 | 微信编辑器 |
| 微信群 | 1 图 + 1 句金句 | 每天 | 原子卡 | 分享图直接发 |
| B站 | 二创 / 解读 | 月 1 | 全部 | 剪映（用 UP 主原视频切片 + 注释） |

### 3.3 关键路径（首月 30 天）

```
第 1 周：3 套切片包定稿（阳的孤独 / 阴的误解 / 哪吒四视角）
第 2 周：每包 1 个小红书 + 1 个抖音 + 1 个视频号（共 9 个素材）
第 3 周：上线「影视四视角」专栏（哪吒），公众号长文 + 1 个 60s 短视频
第 4 周：上线「配对暗号」切片包 + 配对邀请图 push 到已有用户
第 5 周：复盘数据（进站量 / 测试完成率 / 分享图扫码率 / 反馈表填写数）→ 调整下月
```

## 4. 用户与开发者交互机制

### 4.1 已建（v2 demo）
- 站内 footer：「📝 帮我们改进 · 3分钟反馈」→ feedback.html
- 反馈表单：4 段 8 道题（基础 + 体验 + 内测 4 道知识题 + 联系）
- 提交：JSON 复制 / 邮件 / 本地草稿保存（localStorage 防止刷新丢失）
- 跟踪埋点：feedback_click / feedback_ext_click

### 4.2 建议补强
- 反馈后台：腾讯文档在线表（用户共建） / Notion 嵌入 / GitHub Issues（公开）
- 内测题扩展：每张原子卡配 1 道知识题（Q: 你觉得「X」更接近哪个型？），形成"答题 → 反馈 → 推荐下一题"循环
- 周报自动化：每周从 feedback.html 的 localStorage 草稿汇总（用 WorkBuddy 自动化 + 邮件推送）

### 4.3 腾讯文档嵌入（用户可改）
- 形式：把"开放题 + 联系方式"两份表生成嵌入链接（设置仅创建者可读其他人可填）
- 优势：用户（开发者）可随时改问卷结构 / 看汇总 / 加字段，无需重新发布网站
- 限制：嵌入 iframe 跨域、UI 风格需适配站内

## 6. 度量北极星指标

- **MAU / 月活进站数**（首要）— 通过 `?from=*` 渠道埋点
- **测试完成率**（20 道题全做完 / 进站人数）— 目标 ≥ 35%
- **分享图生成量**（saveShareImage 调用 / 测试完成数）— 目标 ≥ 25%
- **分享图扫码进站率**（`?from=share` 进站 / 分享图生成量）— 目标 ≥ 8%
- **反馈表填写率**（feedback.html 完成提交 / 进站人数）— 目标 ≥ 1.5%
- **内测题正确率**（Q1–Q4 答对 / 提交总数）— 越高说明用户理解越深
