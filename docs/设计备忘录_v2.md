## 二、测评重构设计（本轮核心）

### 2.1 三层维度模型总览

| 层 | 维度 | 测什么 | 结果呈现 | 理论依据（语料/总纲） |
|---|---|---|---|---|
| L1 内核层 | 阳 / 阴 | 面对核心冲突时的第一本能 | 型判定（四型 = 内核 × 性别） | B663 判断内核、y0-01 内核是能量属性、y0-02 四型 |
| L2 真实度层 | **假自体（面具指数）** | 人前反应与独处反应的差异、自我评价与实际行为的差异、社会期许偏好 | 面具指数（档位）+ 置信度调节 | y0-04 测不准=面具在答题、B681 女阴阳壳卸面具、B677「以为自己是阳实际是阴」、B87 阳性装逼段位（阳的假自体）、B605/B60 了解阴性能量 |
| L3 场景层 | 情感 / 职场 / 家庭 | 同一内核在不同场景的**呈现差异**（不是不同内核） | 场景能量剖面（三柱图）+ 分场景知识引导 | y0-01 内核是属性不是场景函数（场景只影响呈现）；B117 阴阳分工（职场呈现） |

**理论纪律（防误读）**：场景分只做「呈现剖面」，绝不解释成「你在职场是阳、在恋爱里是阴、你有两个内核」——内核唯一，呈现有别。结果页文案需明写这一点。

### 2.2 判定逻辑与计分方式

**内核分 K（型判定）**
- 题目维度从总纲阶1 差异维度选取 6 个区分度高、可场景化的：情绪表达（y1-07）、沟通风格（y1-10）、决策模式（y1-09）、请求方式（y1-17）、充电方式（y1-11）、能量流向（y1-08）；每维度 ≥3 题。
- 选项计分：每题选项带 k 值（阳 +1 / 阴 −1 / 壳型 0 且记 mask 信号）。
- 维度加权：冲突处理类题（战逃，y0-06 判读核心）权重 ×1.5；决策 ×1.2；其余 ×1.0。
- 内核阳性度 K% = 加权归一（0–100）；K% ≥ 50 判阳 → ×性别 = 四型（沿用旧引擎逻辑）。

**场景分 S（剖面）**
- 每题带 scene 标签（emotion/work/family）；同场景题目分桶聚合 → 各场景阳性度（每场景 ≥3 题）。
- 只渲染剖面图与引导，不参与型判定。

**面具分 M（假自体）**
- 三路信号（详见 2.3）：对偶差异、言行交叉、期许陷阱，各计权累加 → 归一为档位：**低（<30）/ 中（30–60）/ 高（>60）**。
- M 高的两种典型输出：
  - **通用**：型判定置信度降档，结果页提示「面具可能在替你答题」→ 引导问答卡 y0-04（为什么测不准）；
  - **阴戴阳壳信号**（K% 偏阳 + M 高 + 独处题显著偏阴）：出「你的阳可能是一层壳」专属提示 → 引导 B681 卸面具 / B677（以为自己是阳实际是阴）问答卡。**这是新测评相对旧测评最大的增量**：旧测评只能把你判成阳，新测评能提醒你「阳可能是壳」。
  - **阳的假自体信号**（K% 偏阳 + 自大/装逼类题命中）：出「强大是证明给别人看的吗」提示 → 引导 B87 装逼的等级问答卡。

**防误差机制（汇总）**
1. 题量 24–28（每维度 ≥3 题，维度内去掉最极端 1 题再取均值——截尾均值抗单题噪声）；
2. 对偶题人前/独处交叉验证（内核判定以**独处版**为主依据——夜深无人时面具最薄，理论依据 y0-04）；
3. 社会期许陷阱题校准（见 2.3）；
4. 选项随机乱序（沿用旧站 shuffle）；
5. **临界带处理**：|K% − 50| < 10 → 不硬判，结果页出「倾向型 + 置信度：倾向清晰」+ 引导 y0-03（判断没有标准）与 y0-11（判定信号群）问答卡自检（旧站已有 decisive 雏形，升级沿用）。

### 2.3 假自体检测机制（三路信号设计）

| # | 机制 | 做法 | 理论依据 |
|---|---|---|---|
| ① 对偶题（人前版 vs 独处版） | 同一情境在题卷中出现两次：成长线前段以「人前/当下」语境出题，第五章「一个人的深夜」以「独处/回望」语境**回收同一情境**再问。两版极性反转（人前阳、独处阴）计 M+2；幅度差显著计 M+1。叙事上自然成立：深夜重遇白天的事，正是「回味感」的来源 | y0-04 面具在答题；B681 表面镇定内部翻涌；B677 事业做得好（人前阳）但情感依赖渴求（独处阴） |
| ② 言行一致性交叉题 | 行为题（「你当时做了什么」）与自评题（「你觉得自己是什么样的人」）间隔出现、情境同源；极性不一致计 M+1 | B87 装逼即言行差（阳的假自体：说的比做的满）；B605/B60 了解阴性能量（阴的自评常低于实际） |
| ③ 社会期许陷阱题 | 选项中埋一个「人人皆知的正确答案」（圣人选项）与「不体面但真实的反应」；命中圣人选项计 M+1，并用于全局校准其他题的期许偏移 | y0-04；B677 被做局/杀猪盘的机制正是「把期许当真实」 |

**呈现纪律**：面具指数**只给档位不给裸数字**（避免「被诊断感」与精确度错觉——这是对用户的负向体验风险点，见问题 3）；文案口径 = 「内外一致性」，是中性描述不是评判；高面具在产品叙事里是**机会**（看见面具 = 修行的开始），不是缺陷判定。

### 2.4 叙事化题卷：「人生成长线」章节结构

**主轴**：一场人生选择题——用户不是在做题，是在重走自己的来路。

| 章 | 场景 | 题量（MVP） | 功能 |
|---|---|---|---|
| 序章 · 此刻的你 | 混合 | 2 | 热身 + 自评基线（言行交叉的「言」端）+ 期许陷阱题埋点 |
| 第一章 · 童年与家 | 家庭 | 4–5 | 场景分 family；内核维度题（情绪表达/请求方式） |
| 第二章 · 校园与少年 | 家庭/社会 | 3–4 | 过渡场景；信任路径、充电方式 |
| 第三章 · 职场与成年 | 职场 | 4–5 | 场景分 work；沟通风格、决策模式（对偶题「人前版」密集区） |
| 第四章 · 亲密与爱 | 情感 | 4–5 | 场景分 emotion；请求方式/试探、冲突处理（权重 ×1.5 题） |
| 第五章 · 一个人的深夜 | 独白 | 4 | **对偶回收区**（人前题的独处版）+ 言行交叉回收 |
| 终章 · 回望 | — | 1–2 | 收束叙事 + 可选复测引导（「半年后再来答一次，看看剖面变了没」→ 回访钩子） |
| 合计 | | **24–28** | |

**每题 schema（题库字段，供执行 Agent 实现）**：
`{ id, chapter, scene: 'emotion|work|family|mixed', dim: 'y1-07|y1-10|…', weight, kOpts: [{t, k, mask}], isTrap, dualOf: '<对偶题id>', kpLink: ['y1-07'] }`
（`k` = 内核计分 ±1/0；`mask` = 壳信号标记；`dualOf` = 对偶配对；`kpLink` = 该题挂接的知识点——**题目 ↔ 知识卡 ↔ 语料视频三方可溯源**：题 → kpLink → 问答卡 → 原文段带 bv 跳转。）

**示范题 5 道**（题干/选项为设计稿，文案生产时按切片纪律润色）：

**T1 · 第一章 童年与家 ｜ scene:family ｜ dim:y1-07 情绪表达 ｜ 壳选项**
> 小时候考砸了，拿着成绩单站在家门口——推开门前的那一瞬间，你脑子里更像哪一种？
> - A. 先把说辞理好：哪题丢分、下次怎么补——讲清楚了，爸妈就不至于太失望（k:+1 阳·先处理事实）
> - B. 开始排练爸妈的表情——他们一皱眉我就先认错，他们消气比我委屈要紧（k:−1 阴·先处理关系）
> - C. 表情先管理好：进门照常吃饭写作业，他们不问，这事就当没发生（k:0 + mask 信号：表面镇定内心封存）
>
> kpLink: y1-07（情绪表达：阳封存说没事、阴倾倒求接住）｜ 结果引导卡：q-y0-04（测不准=面具）

**T2 · 第三章 职场与成年 ｜ scene:work ｜ dim:y1-10 沟通风格 ｜ 壳选项**
> 复盘会上，你的方案被同事当众指出一处硬伤——你嘴上冒出来的第一句更接近？
> - A. 「确实是我漏了，明天给修正版」——错就认，改完翻篇（k:+1）
> - B. 笑着接住场面，散会后却在心里回放一下午：「他是不是早就看我不顺眼」（k:−1 + y1-08 内耗信号）
> - C. 不接招也不认，轻描淡写绕过去——回头私下把漏洞补得天衣无缝（k:0 + mask：体面优先）
>
> kpLink: y1-10（沟通风格：阳直接解题、阴迂回连接）｜ 对偶：T4

**T3 · 第四章 亲密与爱 ｜ scene:emotion ｜ dim:y1-17 请求方式 ｜ 权重 ×1.5（冲突处理）**
> 和 TA 吵到最凶那晚，TA 摔门出去——半小时后你发的第一条消息更像？
> - A. 「你回来，我们把话说完」——天大的事，说开才能睡（k:+1 直球明说）
> - B. 什么都不发，聊天框开了又关——TA 回来之前，台词我都在心里替 TA 演完了（k:−1 试探/内心戏）
> - C. 发条仅 TA 可见的朋友圈——不直说，但得让 TA 知道我今晚不好受（k:−1 出题试探变体）
>
> kpLink: y1-17（请求方式：阳直球明说、阴出题试探）｜ 场景引导：「阴阳能量在亲密冲突里的不同呈现」

**T4 · 第五章 一个人的深夜 ｜ scene:mixed ｜ 对偶回收（dualOf: T2）｜ 面具检测**
> 深夜两点，白天会上那一幕又浮上来——此刻没有观众，你更会……
> - A. 把逻辑再过一遍：哪句没讲好、下次怎么赢——想着想着就平静了（k:+1，与 T2 一致 → M+0）

> - C. 说不上来哪里不对——白天明明处理得挺体面，此刻心里却空落落的（k:0 + mask：人前独处落差的自觉）

**T5 · 序章 此刻的你 ｜ scene:mixed ｜ 期许陷阱题**
> 朋友深夜打电话来哭诉失恋，你其实明早六点要赶高铁——你的真实反应更接近？
> - A. 困也得听完，TA 这个时候只能靠我了（期许答案 → M+1，不计内核分）
> - B. 听二十分钟帮 TA 把情绪捋顺，然后坦白说明天要早起，约周末见面细聊（k:±按表述分维度）
> - C. 陪着嗯嗯啊啊，一半在听一半在心里叹气——明天还得跟 TA 再聊一遍（k:−1 倾听耗能 + 真实自白）
>
> kpLink: y1-11（充电方式：阳独自完成、阴被人看见）｜ isTrap: true

**双轨题卷（男版 / 女版，分性别校准）——用户拍板新增**

理论依据：性别规训是集体无意识层的**干扰源**（语料 B302/B303《透过男女平等看阴阳》：男尊女卑集体信念把男性放在强者位、女性放在弱者位）——女性天然被期待选「关系性」答案，男性天然被期待选「行动性」答案。同一道题对男女的作答会被规训拉偏，导致内核误判（女性的阴被高估、男性的阳被高估）。

| 设计原则 | 内容 |
|---|---|
| 同构不同文 | 男版/女版的章节结构、维度配比、计分逻辑**完全相同**；差异只在场景情境与选项文案——各自选用该性别规训最强的情境，把规训**暴露**出来而不是被它掩盖 |
| 反规训信号加权 | 选项与本人性别刻板期待相反时（男选示弱求助、女选直面竞争），内核计票权重 ×1.3——能绕过规训作答，说明信号更真实 |
| 题库 schema 增量 | 每题加 `gender: 'male'｜'female'｜'both'`；MVP 产出男版 24 题 + 女版 24 题（约 40% 题两版共用 `both`，60% 分性别撰写） |

同构双轨示例（同测维度 y1-11 充电方式）：
- **男版**：「连轴转了两周，周末终于空出来——你最想？」
  A. 约兄弟打球、组个局，出一身汗才叫歇过来（阳·行动外放）
  B. 关机独处，睡到自然醒，谁也别找我（阳·独处充电）
  C. 先看家里人怎么安排，热热闹闹才像休息（阴·在关系里回血）
- **女版**：「忙了一个月，周末终于空出来——你最想？」
  A. 约闺蜜逛街喝茶，说说话就满血了（阴·在关系里回血）
  B. 一个人待着做点自己的小东西，不被打扰（阳·独处充电）
  C. 先看家里人想干嘛，大家开心我就开心（阴·关系优先变体）

（两版计分逻辑相同；情境与措辞贴合各自性别的真实生活语境，降低「按社会期待答题」的污染。性别选择仍放在序章，选完即进入对应题卷。）

## 三、问答化知识体系（统一数据层）

### 3.1 统一 QA 卡 schema（取代 data_clips.js + data_cards.js 双轨）

```js
var QA_DATA = [ {
  qaId: 'q-y1-07-01',        // q-<kpId>-<序号>（知识点卡）｜ q-c-B664-01（切片科普卡，kpId 空）
  kpId: 'y1-07',             // 可空 = 科普层；非空 = 挂接教材总纲
  category: '阴阳能量',       // 阴阳能量 | 四型人格 | 关系与配对 | 成长课题
  scene: ['emotion','family'], // 场景标签：emotion | work | family（可多选/空）
  forTypes: [],               // 四型相关标记（沿用）
  question: '情绪不舒服时，为什么有人越说越上头，有人越藏越深？',   // 钩子（≤25字规范沿用 v1）
  answerBrief: '一句话结论（来自知识卡 conclusion / 切片 quote 扩写，忠于原文不改义）',
  answer: [ { ts:'04:40', videoId:'B23', bv:'BV…', text:'原文段…' } ],  // 证据段≥1，带时间戳
  quote: '金句（原文，不改义）',
  videoTitle: '…', jumpUrl: 'https://www.bilibili.com/video/BV…?t=…',
  compliance: 'web+mini'      // 合规闸（小程序子集过滤用）
} ];
```

**统一原则（用户拍板：问一问与知识卡片是同一套体系）**：
- 知识卡 ≠ 另一种形态的卡——**知识卡就是挂了 kpId 的问答卡**（多了 answerBrief 与更完整的证据段）；切片科普卡 = kpId 为空的问答卡；
- 已产 66 卡 → 转换规则：每卡出 1–3 问；question 新写（钩子规范），answerBrief 取卡 conclusion，answer 取卡 clips（已带 B 站 link），quote 取金句；editorNotes 不上前台（治学信息下沉原则不变）；
- 一问一卡（v1「一卡一知识点」纪律延伸为「一问一话题」）；`RESULT_GUIDE_MAP` / 场景引导 / 搜一搜 / 问一问分组全部消费同一个 QA_DATA，**全站只有一个内容数据文件 data_qa.js**（+ 语料索引 data_corpus.js + 配对 data_pair.js）。

### 3.2 三板块共享数据层架构

```
                    ┌────────────────────────────┐
                    │  data_qa.js  统一问答卡池    │←─ 66 张已产卡转换 + 新切片 qa + 工具箱拆卡
                    │  （qaId / kpId / scene /     │
                    │   forTypes / question /     │
                    │   answerBrief / answer /    │
                    │   quote / bv / compliance） │
                    └──────┬───────┬───────┬─────┘
                           │       │       │
        ┌──────────────────▼┐ ┌────▼─────────▼───────────┐ ┌────────────────────┐
        │ 问一问              │ │ 测一测                    │ │ 搜一搜              │
        │ category/scene 分组 │ │ RESULT_GUIDE_MAP:        │ │ 全文索引：question> │
        │ 「为你推荐」按       │ │  type × scene × M档      │ │ answerBrief>quote> │
        │ forTypes+scene 过滤 │ │  → 拉取引导卡（含配对报告  │ │ 金句；二级=语料677条 │
        │                    │ │  data_pair.js）          │ │ 命中→B站直跳        │
        └────────────────────┘ └─────────────────────────┘ └────────────────────┘
                    ▲ 三方都只读 QA_DATA，不各建副本；题目 kpLink 也指向同一 qaId 池
```

题目 ↔ 知识 ↔ 语料的溯源链（用户拍板的三方映射）：
`题目.kpLink → 问答卡.qaId（kpId）→ answer[].videoId/bv + ts → B站原话`
反向：从搜一搜命中任意问答卡 → 可见「该知识点出现在测评第几章」（题卷生成的静态回链）。

## 四、视觉设计系统（用户拍板：全新设计，旧站视觉弃用）

> 设计概念：**「晨昏光谱」**——把阴阳从玄学符号翻译成每个人都经历的「昼与夜」：阳 = 晨光（暖、动、向外），阴 = 暮蓝（静、深、向内）。明亮、现代、有内容平台的亲和力，**不用太极图、不用水墨、不用深色神秘风**。

### 4.1 设计原则
1. **去玄学化**：阴阳只以「昼夜/冷暖」的日常意象出现，让新用户 3 秒内觉得「这是讲人的产品」；
2. **内容优先**：问一问信息流是主角，视觉为可读性服务——大问题字、舒展行高、轻装饰；
3. **双色语义贯穿**：全站阳=暖橙 / 阴=暮蓝，用户看颜色就能读能量（标签、图表、结果页共用）；
4. **移动优先**：单列卡片流 + 底部 tab bar；桌面端双列瀑布、留白加大。

### 4.2 色板

| 角色 | 色值 | 用途 |
|---|---|---|
| 纸白底 | `#FAF7F2` | 全局背景（暖调纸感，不刺眼） |
| 卡片白 | `#FFFFFF` | 问答卡 / 面板 |
| 墨黑 | `#232230` | 主文字 / 主按钮底（主按钮不用渐变，稳） |
| 灰雾 | `#8A8794` | 次级文字 / 占位 |
| **阳 · 晨橙** | `#E8913A` | 阳标签 / 阳性图表 /「开始测评」CTA（唯一渐变：晨橙→琥珀） |
| **阳 · 琥珀** | `#D4A574` | 阳系辅助 / 金句强调（传承旧站暖金） |
| **阴 · 暮蓝** | `#4E6E9E` | 阴标签 / 阴性图表 |
| **阴 · 月白** | `#EAF0F7` | 阴系浅底 |
| 分隔 | `#EFEAE2` | 描边 / 分隔线（低对比） |

### 4.3 字体与排版
- 系统栈：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`；
- 问题大字 20–22px/700；正文 15px/400 行高 1.7；金句 16px/500 + 引文样式（左侧 3px 琥珀竖线 + 浅底）；
- 数字（百分比 / 柱状图）`font-variant-numeric: tabular-nums`。

### 4.4 布局与组件
- 容器：移动 ≤720px 单列；桌面 1080px，问一问双列瀑布；
- 导航：移动端**底部 tab bar**（问一问/测一测/搜一搜/我的，毛玻璃白底）；桌面顶部轻导航；
- 组件清单：问答卡（问题大字 → 答案摘要 → 展开证据条）、证据条（时间戳徽标 + 原文 + ▶B站按钮）、场景徽标（🏠家庭 / 💼职场 / 💗情感，浅底小标签）、能量三柱剖面（阳橙阴蓝双色填充）、面具档位徽章（低/中/高，中高才出现）、章节进度条（显示「第三章 · 职场里的你」）、分享预览卡、配对报告卡（双色双栏「你 vs TA」）；
- 图形语言：阴阳意象抽象为**月相 / 昼夜分割线**的极简线条；章节转场用一句场景引言 + 大留白，不做重插画；
- 暗色模式：MVP 不做（远期）。

### 4.5 旧视觉处置
旧站深色 cover、暗夜玄学风全部弃用；旧站四张人像图保留用于结果页型格卡（重新裁切、加浅色底适配新风格）。
