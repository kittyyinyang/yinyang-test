## 一 · 磐磐问题诊断

| 项 | 现状（不合格） | 病根 |
|---|---|---|
| 场景 | 农家院门、柴火、竹筐、扁担 | 劳作写实 → **土气，非仙修** |
| 服饰 | 布衣短打 | 无仙侠服饰语言 |
| 动作 | 抬袖擦汗 | 疲惫感 ≠ 力量感 |
| 结果 | 像个下工的老农 | 丢失对标气质（李逍遥的洒脱 / 东方擎苍的贵气） |

**核心误判**：把「扛」画成了「体力劳动」。磐磐扛的是责任与重量，不是柴火。
**正解**：**东方擎苍式的"扛着天下却不动声色"**——厚重但贵气，劳心但不狼狈。

### 改造方案

| 维度 | 改为 |
|---|---|
| **场景** | 农家院门 → **云海边的守山石阶**（他是守山修士，刚巡完山歇脚） |
| **服饰** | 布衣短打 → **玄色与琥珀色交领长袍**，云纹暗绣，腰束玉带，发束玉冠 |
| **动作** | 擦汗 → **坐石阶，一手搭膝，望远山云海，淡笑**（内敛的力量感） |
| **体态** | 保留厚实肩背（扛的痕迹）、站坐皆稳 |
| **保留** | 憨厚朴实的笑、山形玉坠、暖琥珀主色 |
| **灵宠** | 幼麒麟「岱岱」趴在脚边（见第二节） |

**一句话形象**：刚巡完三千里山界的人，坐在云端石阶上歇一口气，肩上还落着山风，脸上却没什么表情。

## 二 · 四灵宠重新设计

> 设计原则：① **具体生物形态**（不是元素团）② 与主型人格呼应 ③ 自带表情包场景

### ① 小凤凰「焱焱」—— 曙曙（女阳·破局者）

| 项 | 设定 |
|---|---|
| 外形 | 巴掌大幼凤，圆身子，**橙红渐变羽毛**，**三根短尾羽**，小黄喙，豆豆眼，头顶一撮呆毛 |
| 性格 | 傲娇、护主、爱显摆（一得意就喷小火花） |
| 与主型呼应 | 火的爆发力 = 破局的锐；爱显摆 = 曙曙的小得意 |
| 互动 | 停在她肩头/膝头，抢她的点心；她笑它就炸毛 |
| 表情包场景 | 炸毛生气 / 睡着变成小火球 / 偷吃点心被抓包 |

> 现状已获认可，仅微调：**尾羽从火焰状改成三根明确羽片**（更像鸟，更具体）。

### ② 幼麒麟「岱岱」—— 磐磐（男阳·承重者）【主推】

| 项 | 设定 |
|---|---|
| 外形 | 巴掌大幼麒麟，圆滚滚，**暖琥珀色鳞片泛金光**，头上一只**短独角**（未长成），鬃毛像云朵，四只小短腿，**蓬松云尾** |
| 性格 | 憨、慢、**力气大却不自知**（能顶起比自大十倍的东西） |
| 与主型呼应 | 麒麟 = 瑞兽、厚德载物；**扛到习惯成自然** = 磐磐的宿命 |
| 互动 | 跟在他脚边走；他歇着它趴靴子上睡；他扛东西它也要帮忙——**扛着一根小草一脸认真** |
| 表情包场景 | 扛小草一脸严肃 / 走路摔倒 / 睡成一小团云 |

**备选：小玄龟「岳岳」**——更贴"镇守/驮"，赑屃驮碑典故，但**仙气弱于麒麟**。

### ③ 九色鹿「呦呦」—— 汀汀（女阴·连接者）【主推】

| 项 | 设定 |
|---|---|
| 外形 | 巴掌大小鹿，**鹿角是两簇发光的灵枝**（顶端开着小花），月白为底、隐约透出青/金/粉的九色光晕，小蹄 |
| 性格 | 温顺、黏人、**会照顾别的花草** |
| 与主型呼应 | 敦煌九色鹿 = 渡人、舍身；**角上开花 = 滋养他人** = 汀汀的"给" |
| 互动 | 陪她浇花，用角上的小花蹭她的手；灯暗时角上的花会亮起来 |
| 表情包场景 | 角上的花谢了（委屈）/ 用花蹭人撒娇 / 紧张时躲到她身后 |

**备选：玉兔「团团」**——更软萌，但与"连接/渡人"的呼应弱于鹿。

### ④ 玄猫「墨墨」—— 潜潜（男阴·深潜者）【主推】

| 项 | 设定 |
|---|---|
| 外形 | 巴掌大黑猫，毛色是**深夜靛蓝黑**（非纯黑），**琥珀色圆眼**（暗处发光），**尾巴尖是一缕飘动的雾气**，爪子半透明水色 |
| 性格 | 警惕、慢热、**观察型**；主人看书它趴书边假睡，其实耳朵一直动 |
| 与主型呼应 | 猫 = **观察者**：独立克制、不轻易靠近、又渴望陪伴 = 深潜者的推拉 |
| 互动 | 替他先去门口探路再回来"报告"；他装不在家时猫也装睡 |
| 表情包场景 | 假睡耳朵动 / 瞳孔放大被吓到 / 转身不理人但尾巴勾着你的手 |

**备选：小鲲「北北」**——庄子"北冥有鱼"，仙气典故足，但**做表情包不如猫**。

## 三 · 四灵宠总览

| 灵宠 | 主型 | 生物形态 | 一个字 | 记忆点 |
|---|---|---|---|---|
| 焱焱 | 曙曙 | 幼凤（鸟） | **燃** | 三根尾羽，一得意就喷火 |
| 岱岱 | 磐磐 | 幼麒麟（瑞兽） | **扛** | 扛着一根小草一脸认真 |
| 呦呦 | 汀汀 | 九色鹿（走兽） | **给** | 鹿角开花，会照亮 |
| 墨墨 | 潜潜 | 玄猫（家兽） | **察** | 假睡，耳朵一直在动 |

**设计要点**：鸟 / 瑞兽 / 走兽 / 家兽 四种不同生物，剪影互不混淆；每只都有**一个专属动作梗**。
