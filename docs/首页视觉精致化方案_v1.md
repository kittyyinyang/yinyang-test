# 阴阳人格 · 首页入口视觉精致化方案 v1

> 性质：纯设计研究文档。只读现状（index.html 共 2998 行，主样式表 L7-521、核心知识卡样式 L524、功能样式块 L544；首页 HTML L670-796；晨昏轮 SVG L675-734 + defs L630-651），产出「首页入口的图案与排版精致化」方案。**不修改任何代码文件。**
> 设计立场：**精致化而非推翻**。用户明确喜欢的既有元素——晨昏轮、阳橙/阴蓝双色、国风、印章——全部保留并升级质感；新增的一切都从「纸白/墨黑/晨橙/暮蓝/朱砂」现有 token 中取材，零新增外部资源，维持离线单文件约束。
> 目标效果一句话：**让首页首屏从「信息完整但略满」变成「一轮晨昏悬于纸面、印题对应、入口有身份」的东方门面。**

## 一、现状评估

### 1.1 晨昏轮（wheel）—— 已精致，缺「呼吸」与「霞光」

**优点（保留不动的地基）**
- 结构设计很成熟，五层叙事清晰，见 `index.html` L675-734：
  1. 墨晕底噪层 `wgInk`（L676-680，三组圆 + feTurbulence 毛边，opacity .1）→ 模拟「印泥渗纸」；
  2. 暖金 halo 光圈（L681，`#D4A574` stroke-width 10 + blur 12）→ 晨光外溢；
  3. `wheel-orbit` 轨道层（L682-700：双细环 + 虚线星环 + 四向刻度 + 星点 + 云纹曲线，60s 自转）；
  4. `wheel-core` 昼夜层（L701-733：`wgDayG`/`wgNightG` 径向渐变、太阳、月牙、S 光带 `wgSG`、星点、中心点）；
  5. CSS 层：`.wheel` L98 `drop-shadow(0 20px 34px rgba(53,50,80,.13))` 有深度。
- **S 光带**（L729-730）是一条穿过昼夜交界、从晨橙渐变到暮蓝的太极 S 变体——这是全站最有记忆点的视觉叙事，必须继续当主角。

**可提升点（证据）**
| # | 缺口 | 证据 |
|---|------|------|
| W1 | **昼夜半圆是硬切**，交界线没有「霞光」过渡——一天中最美的那一分钟（日出/日落）没有画出来 | L702-703 两个半圆 fill 直接相邻 |
| W2 | **太阳没有辉光、月亮没有月晕**——光源感弱，靠填色而非发光 | L704 太阳是纯色圆；L717 月牙是纯 fill |
| W3 | **整轮静止、只有轨道转**——昼夜轮本体的「晨昏推进」感缺失；S 光带是静态的 | L99-100 仅 `.wheel-orbit` 有动画 |
| W4 | **光影层次单薄**——昼半圆缺高光、夜半圆缺暗部，昼夜交界无明暗转折 | core 内仅 1 条 `r140` 细描边（L731） |
| W5 | **移动端 264px 过重**（见 1.2 E4）；且 60s 自转在低端机持续占用合成层 | L98 / L99-100 |
| W6 | 外圈描边质感单一：`r166` 虚线环（L684）已不错，但轮缘与背景之间缺少一层更细的「星尘环」 | L681-684 |

### 1.4 氛围层 —— 单项都成立，缺「一张清单」

- `brush-divider`（L93-94 CSS、L750 HTML）：单根 2.2px 曲线，`wgBrush` 渐变（L640-642）已有橙→朱→蓝渐隐，**很好，但缺少「干笔飞白」的书写质感**。

- `body` 背景（L26-37）：双 radial 色晕 + 噪点（L39-42）已是「纸面」基底，够用。
- `brand-seal`（L57-61）：朱砂双字方印精致度已高，本轮仅做 1 条微调建议（P2）。

## 二、晨昏轮精致化

设计意图：**给轮子加「光」与「呼吸」**——霞光描过晨昏线、太阳亮起辉光、月牙泛起月晕、整轮极慢地醒着（呼吸），而轨道继续自转。全部在现有 SVG 结构上叠加，不删任何现有元素。

### 2.1 SVG 结构改进（P1，改 defs L630-651 + wheel L675-734）

**① 晨昏霞光带（最高价值改动）**
在现有 S 光带（L729-730）与昼夜交界处叠一条霞光描边。新增 defs：

```svg
<linearGradient id="wgTwilight" x1="0" y1="1" x2="1" y2="0">
  <stop offset="0" stop-color="#E8913A" stop-opacity=".7"/>
  <stop offset=".5" stop-color="#C65A6B" stop-opacity=".55"/>
  <stop offset="1" stop-color="#4E6E9E" stop-opacity=".7"/>
</linearGradient>
```

在 L730（S 光带）之后插入同路径、`stroke="url(#wgTwilight)"` 的霞光线：

```svg
<path d="M210,70 C150,103 150,177 210,210 C270,243 270,317 210,350"
      fill="none" stroke="url(#wgTwilight)" stroke-width="2.4"
      stroke-linecap="round" opacity=".5"/>
```

> 视觉：晨橙→玫紫→暮蓝的细线紧贴晨昏线游走，把「硬切」变成「霞光一秒」，与 `wgSG` 的乳白亮带形成「霞+光」双层。

**② 太阳辉光 + 月牙月晕**
在太阳圆（L704）之前加辉光，在月牙（L717）之后加月晕。新增两个 defs：

```svg
<radialGradient id="wgSunGlow" cx="50%" cy="50%" r="50%">
  <stop offset="0" stop-color="#FFF3D6" stop-opacity=".9"/>
  <stop offset=".55" stop-color="#F6C384" stop-opacity=".35"/>
  <stop offset="1" stop-color="#F6C384" stop-opacity="0"/>
</radialGradient>
<radialGradient id="wgMoonGlow" cx="50%" cy="50%" r="50%">
  <stop offset="0" stop-color="#F2F6FC" stop-opacity=".6"/>
  <stop offset="1" stop-color="#F2F6FC" stop-opacity="0"/>
</radialGradient>
```

插入点：
```svg
<!-- L704 之前 -->
<circle cx="262" cy="146" r="34" fill="url(#wgSunGlow)"/>
<!-- L717 之后 -->
<circle cx="154" cy="277" r="30" fill="url(#wgMoonGlow)" opacity=".55"/>
```

**③ 星尘内环（光影层次 W4 的最小解法）**
在 core 内层（L731 `r140` 细环附近）加一圈极细星尘环，与轨道虚线（L684）呼应但更细：

```svg
<circle cx="210" cy="210" r="152" fill="none"
        stroke="#FFF3DE" stroke-opacity=".16" stroke-width="1"
        stroke-dasharray="1 23" transform="rotate(-45 210 210)"/>
```

**④ 昼高光 / 夜暗部（W4 的进阶，P2 可选）**
用两条半透明描边模拟体感：沿 S 线两侧各加 1px 白/墨描边（`stroke="#FFFFFF" opacity=".07"` 贴在昼半圆上缘、`stroke="#1C2A44" opacity=".12"` 贴在夜半圆下缘），不新增滤镜、纯描边即可。

### 2.2 CSS 动效（P1，改 L96-101 区块）

保留 60s 轨道自转，新增三个「慢到不打扰」的动效：

```css
/* 晨昏轮本体：极慢呼吸（约 1 分钟 1 个周期内的微幅缩放） */
.wheel-core{transform-box:view-box;transform-origin:50% 50%;
  animation:wheelBreath 9s ease-in-out infinite;}
@keyframes wheelBreath{50%{transform:scale(1.008);}}

/* S 光带流光：光斑沿晨昏线缓慢游走（仅 stroke-dashoffset，合成器级） */
.wheel-glow{stroke-dasharray:8 40;animation:glowFlow 7s linear infinite;}
@keyframes glowFlow{to{stroke-dashoffset:-48;}}
```

> `wheel-glow` 加在 L730 的 `wgSG` 光带 path 上（HTML 补一个 class）。若担心 stroke 动画在部分安卓低端机卡顿，可把 `wheel-glow` 动画降级为静态（见 2.3）。

### 2.3 性能降级策略（P0，改 media query 区 L474-476 附近）

```css
/* 移动端：降尺寸（E4 主刀） + 放慢自转 */
@media (max-width:720px){
  .wheel{width:200px;height:200px;}
  .wheel-wrap{margin:0 0 6px;}
  .wheel-orbit{animation-duration:90s;}
}

/* 低功耗 / 视觉敏感：三种动效全部关闭（已有全局 reduce，这里补视差兜底） */
@media (prefers-reduced-motion:reduce){
  .wheel-core,.wheel-glow{animation:none!important;}
}
```

### 2.4 鼠标视差（P1，仅桌面精确指针设备，JS 约 8 行）

CSS 侧（加在 ≥721px 媒体查询内）：

```css
@media (hover:hover) and (pointer:fine){
  .wheel-wrap{transition:transform .6s cubic-bezier(.22,.61,.36,1);will-change:transform;}
}
```

JS 侧（加在 `renderHome()` 或初始化段）：

```js
if(window.matchMedia('(hover:hover) and (pointer:fine)').matches
   && !window.matchMedia('(prefers-reduced-motion: reduce)').matches){
  var w=document.querySelector('.wheel-wrap'),h=document.querySelector('.hero');
  if(w&&h) document.addEventListener('pointermove',function(e){
    var b=h.getBoundingClientRect();
    if(e.clientY<b.top-40||e.clientY>b.bottom+40||e.clientX<b.left||e.clientX>b.right) return;
    var tx=(e.clientX-b.left)/b.width-.5, ty=(e.clientY-b.top)/b.height-.5;
    w.style.transform='translate3d('+(tx*10)+'px,'+(ty*10)+'px,0) rotate('+(tx*1.5)+'deg)';
  });
}
```

> 只写 `transform`（合成层），无重排；`prefers-reduced-motion` 双重兜底；触屏（无 hover）不启用。
