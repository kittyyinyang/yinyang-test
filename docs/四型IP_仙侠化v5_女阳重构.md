```
中国古典仙侠插画风格，大头身比约1:2.5的Q版修士形象，仙气飘逸，
衣袂与发带轻盈飘动，周身有淡淡的灵气光晕与流光粒子，

扁平插画带柔和渐变与微光，盲盒手办级质感，画面无文字
```

**与旧卡通版的三处关键差异**：

| 维度 | 旧（卡通） | 新（仙侠） |
|---|---|---|
| 服饰 | 高领毛衣 | 古风改良：交领/广袖/丝绦/玉饰 |
| 氛围 | 纯色背景 | 云海、灵气、流光粒子 |
| 材质 | 扁平渐变 | 丝绸柔光 + 玉石温润 + 金饰哑光 + 灵光半透 |
| 保留 | **大头 Q 版身比（可爱感不能丢）、四型主色、壳的概念** | |

## 二 ·「壳」在仙侠语境的重译

原概念（壳 = 人格外衣）在仙侠语境下更合理——**每个修士都有自己的本命灵物/洞府**：

| 型 | 旧（卡通） | 新（仙侠） | 意象升级 |
|---|---|---|---|
| 磐磐 | 暖金山岩环 | **镇山石台 / 守山灵印** | 扛 = 镇守 |
| 曙曙 | 绯红茧壳 | **凤凰蛋 / 涅槃火茧** | 破 = 涅槃 |
| 汀汀 | 莲瓣水环 | **莲台 / 灵泉** | 给 = 渡人 |
| 潜潜 | 深青贝壳 | **灵贝 / 玄水府** | 潜 = 闭关 |

## 三 · 女阳「曙曙」仙侠版完整设定

### 三重性拆解

| 层次 | 人格内核 | 视觉元素 |
|---|---|---|
| **凤凰**（神性） | 浴火重生 | 从**凤凰蛋**破壳而出，身后有**凤凰火羽虚影**，脚踩火纹 |
| **女战士**（外） | 冲锋陷阵，打破枷锁 | **轻战甲 + 战裙**，高马尾束发，**脚下碎裂的封印锁链** |
| **小公主**（内） | 内心柔软，保留爱的连接 | **腰间小铃铛** / 发带蝴蝶结 / **指尖牵一缕灵光丝线**连向远方 |

### 配色

| 部位 | 色 | 说明 |
|---|---|---|
| 主色 | 赤朱 #D2453C | 凤凰火 |
| 辅色 | 暗金 #B8860B | 战甲与凤羽 |
| 点缀 | 柔粉 #F4C0D1 | 小公主感（铃铛/发饰/战裙内衬） |
| 背景 | 暖橙金云海 | 涅槃的火光天 |

### 一句话形象

> **她刚从凤凰蛋里劈开一条路出来，战甲上还沾着火，腰间的铃铛却在叮当响。**

## 五 · 执行方案

| 阶段 | 工具 | 目的 | 成本 |
|---|---|---|---|
| 1. 试稿（1 张曙曙） | **即梦**智能参考（风格参考维度 45-65） | 最快锁定仙侠方向 | 免费额度 |
| 2. 定稿四型 | **混元文生图** HY-Image-3.0-Plus | 干净无水印 + 可商用 | 小程序赠送额度 |
| 3. 24 枚表情 | **混元图生图** HY-Image-v3.0-I2I | 以定妆照锁角色 | 小程序赠送额度 |

**为什么试稿用即梦**：风格大改，混元文生图一次成形率低；即梦已验证、中文理解最好、可边看边调。方向锁定后再用混元批量，省额度。

### 混元调用（需你提供三件套）

| 信息 | 在哪拿 |
|---|---|
| 环境 ID | 云开发控制台 → 环境管理 → 环境 ID |
| 云函数名 | AI → 生图模型 → 一键创建云函数后的函数名 |
| 服务端 API Key | 环境管理 → API Key 配置 → 创建 |

调用格式：
```
POST https://{环境ID}.api.tcloudbase.com/v1/functions/{云函数名}
Header: Authorization: Bearer {API Key}
Body: {"prompt":"...","size":"1024x1024"}
```
