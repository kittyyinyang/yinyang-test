## 一 · 系列概念：壳中的小人

**一句话**：每个人心里都住着一个小人，坐在自己的人格外壳里。测一测，看见你的壳。

**设计公式**（从参考图逆向拆解，四型共用）：

```
大头 Q 版（头身比 1:2.5）
× 住在「主题容器」（壳）里
× 指尖/手与元素的一个「叙事瞬间」
× 蓬松头发里藏「能量纹理」
× 高领毛衣
× 低饱和 1 主色 + 1 辅色 + 纯净浅色单色背景
× 扁平 + 柔和渐变 + 微光点（盲盒手办插画质感）
```

**为什么这个公式不山寨**（对照上一版失败原因）：
| 上一版问题 | 这一版解法 |
|---|---|
| 简笔无材质 | 扁平 + 渐变 + 微光点的盲盒质感 |
| 无记忆点 | 「壳」一个强符号扛全场，四型四壳 |
| 无世界观 | 壳 = 人格外衣（与产品理论「假自体/阴壳」直接挂钩） |
| 人物全身难画 | 坐姿 + 藏壳中，规避手脚与比例难点 |
| 情绪靠猜 | 每型一个「叙事瞬间」动作 |

**世界观彩蛋（给运营留的钩子）**：
- 两壳相触 = 阴阳合抱（配对功能的视觉基础）
- 四壳拼合 = 一枚完整太极（集卡/晒图的收集动力）
- 传播钩子：「你的壳，是什么颜色？」

## 二 · 四型设定卡

### ① 男阴 · 深潜者「潜潜」（✅ 已有定稿参考图）

| 项 | 设定 |
|---|---|
| 壳 | 深青色花瓣状贝壳，壳内盛浅水 |
| 叙事瞬间 | 指尖轻点水面，涟漪荡开，星光随波浮起 |
| 头发 | 深靛蓝蓬松短发，发丝间藏星点纹理 |
| 色系 | 毛衣深紫靛 #2E2A5C ｜ 壳青蓝 #1B9CB8 ｜ 背景浅蓝 #D6E9F2 |
| 情绪 | 平静、内省、看得清但说得少 |
| 型格锚 | "潜得最深的人，看得最清，也说得最少" |

### ② 男阳 · 承重者「磐磐」

| 项 | 设定 |
|---|---|
| 壳 | 厚重圆润的山岩环（或小铜鼎），稳稳落地，带石材哑光质感 |
| 叙事瞬间 | 双臂环抱一只悬浮的发光小山，抱得很紧、按得很稳 |
| 头发 | 深琥珀棕蓬松短发，发丝间藏金砂云纹 |
| 色系 | 毛衣深琥珀棕 #6B4A2B ｜ 壳暖金 #B8804A ｜ 背景米色 #F3E8D8 |
| 情绪 | 平静坚定，嘴角微抿，眼神温和有力 |
| 型格锚 | "我扛住了全世界，却扛不住一句'你也可以脆弱'" |

### ③ 女阳 · 破局者「曙曙」

| 项 | 设定 |
|---|---|
| 壳 | 绯红色茧壳/蛋壳，裂开一道大口，壳内有暖光溢出 |
| 叙事瞬间 | 半个身子探出裂缝，一手撑着壳沿，长发被风掀起——刚破壳的瞬间 |
| 头发 | 深红棕飞扬短发，发丝间藏火星光点 |
| 色系 | 毛衣绯红 #A83A3A ｜ 壳赤朱 #D2453C ｜ 背景浅粉 #F8E4DC |
| 情绪 | 眼神亮而锐，嘴角一丝不服输的笑 |
| 型格锚 | "不是喜欢一个人扛，是每次想被接住，都扑了空——所以我自己破壳" |

### ④ 女阴 · 连接者「汀汀」

| 项 | 设定 |
|---|---|
| 壳 | 月白色莲瓣环 / 层层水波纹环，柔和舒展 |
| 叙事瞬间 | 掌心托一盏小灯，灯罩里映出另一个小人的剪影——灯照的永远是别人 |
| 头发 | 深棕带青的柔顺长发，发丝间藏月光丝纹 |
| 色系 | 毛衣月青 #3E6E68 ｜ 壳月白青 #7FB3AE ｜ 背景浅青绿 #E4F0EA |
| 情绪 | 温柔含笑，眉眼弯弯 |
| 型格锚 | "用心连接每一个人，却常常忘了自己" |

## 三 · 图生图 Prompt（以潜潜图为参考）

**使用方法**：上传潜潜参考图 + 贴以下 prompt（风格锚部分一字不改）。

### 风格锚（共用前缀）

```
Q版卡通角色插画，大头身比约1:2.5，人物坐在一个花瓣状的壳形容器中，
蓬松深色短发发丝间藏有微光纹理，穿高领毛衣，一只手做出与元素互动的动作，
扁平插画风格带柔和渐变和微光点缀，盲盒手办插画质感，
纯净浅色单色背景，人物居中，画面无文字，保持与参考图完全一致的画风和质感
```

### ②磐磐（男阳·承重者）——差异部分

```
【风格锚】
壳改为：厚重的暖金色山岩环，落地沉稳，哑光石材质感
人物改为：深琥珀棕色蓬松短发，发丝间藏金砂云纹，穿深琥珀棕高领毛衣
动作改为：双臂环抱一只悬浮的发光小山，抱得很紧
背景改为：温暖米色
情绪：平静坚定，嘴角微抿
```

### ③曙曙（女阳·破局者）——差异部分

```
【风格锚】
角色改为：一个女孩，深红棕飞扬短发，发丝间藏火星光点，穿绯红色高领毛衣
壳改为：绯红色茧壳，裂开一道大口，壳内暖光溢出
动作改为：半个身子从裂缝探出，一只手撑着壳沿，长发和衣角被风掀起
背景改为：浅粉色
情绪：眼神明亮锐利，嘴角一丝不服输的笑
```

### ④汀汀（女阴·连接者）——差异部分

```
【风格锚】
角色改为：一个温柔的女孩，深棕带青的柔顺长发，发丝间藏月光丝纹，穿月青色高领毛衣
壳改为：月白色莲瓣环与层层水波纹
动作改为：双手掌心托起一盏小灯，灯罩里映出一个小人剪影
背景改为：浅青绿色
情绪：温柔含笑，眉眼弯弯
```

### 表情包延展（拿到定妆照后）

以定妆照为参考图，改动作和表情即可（壳、发色、毛衣、背景全部不动）：

```
【风格锚】+ 保持角色和壳完全不变，只改动作与表情：
动作改为：[如：整个人缩进壳里只露头顶 / 壳上多出一座小山压得他一颤]
表情改为：[如：眼睛瞪大 + 嘴巴变小圆圈]
```

| 步 | 动作 | 工具 | 成本 |
|---|---|---|---|
| 1 | 上传潜潜参考图，出磐磐/曙曙/汀汀 各 4 张候选 | Nano Banana（免费 100/天）或即梦 | ¥0 |

**一致性三原则**（同前，更严）：
1. 同型所有表情，参考图 = 该型定妆照，不换
2. 风格锚前缀一字不改
3. 壳、发色、毛衣色、背景色在 prompt 中重复声明（颜色是最容易漂的）
