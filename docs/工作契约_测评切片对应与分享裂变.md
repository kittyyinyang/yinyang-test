## 三、切片 schema（Agent B 产出 `data/data_clips.js`）

```js
var CLIPS_DATA = [
  {
    clipId: 'c-B664-01',            // c-<视频id>-<序号>
    videoId: 'B664', bv: 'BV1Fz8i67EgE',
    videoTitle: '阴阳能量的本能第一反应',
    format: 'qa',                   // 'qa' 问答形 ｜ 'passage' 原文段
    question: '面对冲突，阳和阴的第一反应为什么完全不同？', // qa 必填；passage 留空
    topic: '战逃本能',              // 短标签
    category: '阴阳能量',           // 归类：阴阳能量 | 四型人格 | 关系与配对 | 成长课题
    forTypes: ['yang-male','yin-male'], // 该切片与哪型相关；通用空数组 []
    startTs: '00:00', startSec: 0,
    answer: [                        // qa：2–4 段；passage：同结构但无 question
      { ts: '00:00', text: '战逃反应你知道吧，就是 fight or flight。阴性能量它的第一本能启动的反应就是 flight；阳性能量第一本能启动的就是 fight，战斗。' }
    ],
    quote: '阴性能量的第一本能是 flight，阳性能量是 fight——内核不同，第一反应不同。', // 1 句精炼金句（不改义）
    jumpUrl: 'https://www.bilibili.com/video/BV1Fz8i67EgE?t=0'
  }
];

// 测评结果 → 切片一一对应（结果页各模块直接按此渲染）
var RESULT_CLIP_MAP = {
  'yang-male': { traits:['c-B16-01'], belief:['c-B377-01'], growth:['c-B48-01'], relation:['c-B56-01'] },
  'yang-female': { traits:[], belief:[], growth:[], relation:[] },
  'yin-female':  { traits:[], belief:[], growth:[], relation:[] },
  'yin-male':    { traits:[], belief:[], growth:[], relation:[] }
};
// 结果页模块 ↔ 切片组：traits=人格底色（画像）；belief=核心信念；growth=进化课题/成长步骤；relation=关系模式与配对
// 每型每组 1–3 条，clipId 必须存在于 CLIPS_DATA。
```

**选片与改写纪律**：`answer[].text` 与 `quote` 必须来自语料原文（ASR 音近错字可最小还原，如「羊」→「阳」），不得创作；每条切片单一话题、时长 1–3 分钟；每条 answer 2–4 段、总字数 80–300；`forTypes` 供结果页/问一问按型过滤。

## 五、「问一问」模块规格（Agent A 实现）

- 入口：导航栏独立 tab「💬 问一问」；结果页底部与切片卡片均可跳转并自动定位到对应问题。
- 形态：按 `QA_CATEGORIES` 分组的**手风琴问题列表**（只渲染 `format:'qa'` 切片，默认全收起）；点击展开 → `answer` 原文段（带各自时间戳与 B站直跳按钮）+ `quote` 金句高亮。

## 六、分享裂变规格（Agent A 实现）

1. **结果页新增「分享」卡**：两个动作——
   - ①「复制分享文案」：生成文案（示例：`我测出了【男阳 · 承重者】——能量内核测评，10 题看穿你在关系里的第一反应。来测测你是谁，还能看咱俩配不配 → <链接>`），`navigator.clipboard` 写入 + 降级 `document.execCommand`；文案含**带参链接** `https://kittyyinyang.github.io/yinyang-test/?t=<type>&from=share`（本地 file:// 调试用 `location.href.split('?')[0]`）。
   - ②「微信分享引导」：检测 `MicroMessenger` UA 时显示提示层「长按截图 → 发给朋友」，文案同样可复制。
2. **带参回收（裂变闭环）**：页面加载读 URL `?t=`（分享者四型）。访客测完出结果时，若 URL 带 `t` 且与本人类型不同 → 结果页顶部插入「**你 & TA 的配对报告**」卡：显示分享者类型 + 双向配对建议（查 `data_pair.js`）+ CTA「测测 TA 会不会也想知道 → 再分享」。
