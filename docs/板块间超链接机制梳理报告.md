## 二、核心跳转机制说明

### 1. `goQaCard(qaId)` —— 全站知识卡直达（主枢纽）
- 校验 `qaById(qaId)` 存在 → 记追踪/已读 → `location.hash='#qa'` → `route()` 展开目标卡
- 目标卡不在当前列表（过滤/分组导致）→ **自动重置过滤重渲染**，保证直达成功
- 全站 3 处字面量 + 数百处动态引用，静态/动态审计均 0 断链

### 2. `goSearch(kw)` —— 搜一搜入口
- 设 hash → 填搜索框 → `runSearch()`；标签脑图/高频标签 chip 均走此路

### 3. `runSearch()` —— 语料跳转关键链路
- 语料条目 ▶ B站 = `https://www.bilibili.com/video/{c.bv}?t={CORPUS_SENT_FIRST[c.id]}`
- **依赖两层**：`c.bv`（data_corpus_refined.js 权威） + `CORPUS_SENT_FIRST[c.id]`（首句秒位，corpus_sent_first.js）
- 本轮 bv 勘误已把这两层全部修正，实测 B663=「从情绪到信念」→ `BV1M4hG6wEfy?t=0` ✅

### 4. `GUIDE[type]` —— 测一测 → 问一问（deep/scene/shell）
- deep：结果页④按型推荐 6 卡；scene：雷达面板+分场景卡组；shell：阴壳提示卡组
- **发现并修复的真实断链**：4 张四型功课卡（q-kp-b*-01）kpId 与 qa_core4 画像卡撞车 → 被装配过滤出池 → GUIDE 5 处引用失效。修复：kpId 加 `-gk` 后缀重新入池（QA 池 261→265）

### 5. `healFindCard(kp)` —— 成长页 → 问一问
- HEAL_METHOD/HEAL_PRACTICE/HEAL_GROUPS 引用 kpId 或 qaId，统一转 qaId 后 goQaCard

### 6. B站切片双模式
- 桌面端：`toggleEvPlayer` 懒建 iframe（bvid+秒位）站内播，收起/切卡销毁防并发
- 移动端：直接 `window.open` 跳 B站
