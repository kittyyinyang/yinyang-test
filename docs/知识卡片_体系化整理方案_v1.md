## 五、治理规则

1. **一卡一知识点**：同 kpId 只产一张核心卡，新卡覆盖旧卡（qaId 保持 `q-<kpId>-01`，装配层去重 core 优先）。
2. **分类以 V3.3 章节为准**；stage 按教学序阶数（0–5）。
3. **职责边界**：卡片呈现维度区分、不判定阴阳；判定归测一测；收尾可引导「去测一测」。
4. **evidence 铁律**：真实时间戳 + 真实 bv，逐句核验；复用已验证切片需在 editorNotes 注明来源。
5. **配对矩阵去重**：16 卡为「主卡 + 视角卡」结构（如 p13 主卡 + p31 视角卡），视角卡共享主卡证据，insight 侧重各自视角。
6. **双生/紫圈/九楼** 内容仅 web 另册，不进主池；涉性主题 compliance:'web'。
7. **装配**：新批次 `data/qa_core<N>.js`（var QA_CORE<N>，UTF-8 无 BOM），前端 script 接线一行即生效。
