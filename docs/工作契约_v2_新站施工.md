## 二、站点规格（Agent A）

### 2.1 结构与路由
- **门户首页（`#home`）**：三板块功能介绍卡 + 入口（每卡：板块名 + 一句话功能介绍 + 「进入」按钮 + 精选内容预览 1–3 条）；已测用户显示「我的上次结果」快捷条；
- **问一问 `#qa`**：问答卡信息流（独立主页）。分组：阴阳能量/四型人格/关系与配对/成长课题；场景筛选：情感/职场/家庭；「为你推荐」（有历史结果时按 forTypes+scene 过滤置顶）；卡片=问题大字+答案摘要，展开=答案+证据段（时间戳徽标+原文+▶B站按钮）+金句+「分享这一条」；
- **测一测 `#test`**：独立主页（沉浸封面：钩子文案 + 开始按钮 + 历史结果入口 + 「约 4 分钟 · 20 题」提示）；答题为章节流；
- **搜一搜 `#search`**：输入 → 两级召回（问答卡 > 语料条目 677 条）；命中问答卡高亮 question；语料条目带篇/子组徽标+标签+B站直达；**双生/九楼等深水内容：无任何入口与运营位，仅关键词命中时召回，条目带「进阶」小徽标**；
- **我的 `#me`**：历史结果列表（日期/型/职场·情感·家庭剖面摘要）、中断续答入口、清空记录；
- 导航：移动端底部 tab bar（首页/问一问/测一测/搜一搜 + 我的入口并入首页或 tab）；桌面顶部轻导航；hash 路由，默认 `#home`。

## 三、测评规格（Agent B 出题卷，Agent A 实现引擎）

### 3.1 题卷结构（每版 20 题，男/女双轨）
```
序章（不计题）：性别选择 → 加载对应题卷 → 章节叙事开场
第一章 小时候的家（4 题，scene:family）
第二章 校园与少年（3 题，scene:school）
第三章 职场里的你（4 题，scene:work，含对偶组A人前版）
第四章 亲密关系里的你（4 题，scene:love，含对偶组B人前版 + 陷阱题1）
第五章 深夜独处的你（5 题，scene:self，对偶回收2题 + 陷阱题1）
（终章回望为结果页叙事文案，不设题）
```

### 3.2 每题 2 选项制（用户拍板）
- 每题只有 **2 个选项：一个阳、一个阴**，无中间项；`kOpts:[{t,k:+1},{t,k:-1}]`；
- **每题对应一张知识卡片**（`kpLink` 必填）——结果页/答完每章可回看「你为什么这样答」；题卡一一对应，讲清「为什么这个情境下阴阳会有这个区分」；
- **维度覆盖清单（20 题必覆盖，题数可按维度配 1–2 题）**：战逃本能（y1-02，权重×1.5）、能量方向（y1-01）、自我强弱（y1-03）、价值权重（y1-04 事业vs感情）、核心信念（y1-06 无能恐惧vs不配得，权重×1.5）、内外耗（y1-08，权重×1.5）、充电方式（y1-11）、情绪表达（y1-07）、沟通风格（y1-10）、决策模式（y1-09）、边界感（y2 相关卡）、请求方式（直球vs试探）、信任路径（先信任再投入vs先投入再验证）、对控制/纠缠的反应。以上任选至 20 题，**全部需有 kpLink 与语料依据**；
- 假自体检测在 2 选项制下的适配：**对偶题**（人前版与独处版极性反转计 M+2，同向计 M+0）+ **陷阱题**（「体面选项」vs「真实选项」两难，选体面计 M+1）——M 只用于触发科普卡与阴壳提示（K 偏阳+独处题显著偏阴 →「你的阳可能是一层壳」提示）；
- **反规训加权**：选项与答题者性别刻板期待相反时计票 ×1.3（男选示弱求助/关系优先，女选直面竞争/独处充电）；
- 双轨：约 40% 题两版共用（`gender:'both'`），60% 分性别撰写（男版/女版情境各自贴合真实生活语境）。

### 3.3 出题纪律（用户拍板，最高优先级）
1. **学习旧 10 题的表述质感**（旧题在 index.html `QUESTIONS`，已小范围内测）：题干与选项要像**一个真实的人在真实场景下会有的正常选择**——不理想化、不贴理论标签、不写「作为阳性能量你会…」这种出戏文案；
2. **社会赞许度拉平**：每题阴阳两选项**不能有明显好坏倾向**——读者不应能猜出「哪个答案更好」；两选项都写成人之常情，一个是「向外/直面」的常情，一个是「向内/连接」的常情；
3. 每题题干带场景叙事感（承接章节引言），题目之间有情节呼应（第一章的因、第五章的果）；
4. 每题溯源表：题号 → kpLink → 语料依据（视频 id+时间戳范围）。

### 3.4 题卷 schema（`quiz_male.js` / `quiz_female.js`）
```js
var QUIZ = [ {
  id:'M01', gender:'male',           // male 文件内含 both+male 题；female 同理
  chapter:1, chapterTitle:'小时候的家', scene:'family',
  intro:'第一章引言（2–3 句叙事）',   // 每章首题带，其余空串
  text:'题干',
  opts:[ {t:'阳选项文案', k:1, warp:0}, {t:'阴选项文案', k:-1, warp:0} ],  // warp=1 标记反规训加权选项
  dualOf:'', isTrap:false,           // 对偶配对题id / 陷阱题标记
  kpLink:'y1-07', kpCard:'q-y1-07',  // 挂接知识点与问答卡 qaId
  weight:1.0                          // 1.5=核心维度；1.3 加权在 warp 上体现，二者可叠
} ];
var QUIZ_META = { version:'v2-demo', total:20, chapters:[...章题名] };
```
