## 三、标题公式库（爆款句式模板，agents 生成新钩子时套用）

1. **对照式**：「同一件事，两种人：A____，B____」
2. **反直觉式**：「____的人，不是____，而是____」（他不是冷漠，是在控制不陷进去）
3. **悬念式**：「四个字/一张图/20道题，看穿____」
4. **共鸣式**：「为什么你总是____——原来是因为____」
5. **身份式**：「测出『承/破/连/潜』的进」「____型人格的自我修养」
6. **MBTI 蹭量式**：「MBTI 之后，试试这个中国自己的____」「MBTI 测不准的人，____」

| 导流口径 | 小红书：评论区/简介引导搜「阴阳人格手记」（不放链接）；视频号：直接挂小程序/公众号组件（小程序上线前挂公众号）；抖音：主页+粉丝群暗语，不出现微信字样 |
| from 参数 | 落地链接一律带 `?from=<支柱><平台><序号>`（如 p3x01=支柱3小红书01；平台码 x=小红书 d=抖音 s=视频号 g=公众号），命名与 content_graph.js 一致 |

## 五、轮换规则（内容日历生成器的输入）

1. 周配比：P1×2 ｜ P2×2 ｜ P3×2 ｜ P4×1 ｜ P5×0.5 ｜ P6×0.5（每周约 8 条全网）；
2. 单平台周更：小红书 3–4、视频号 2–3、抖音 2–3（同素材跨平台改标题封面）；
3. 同一支柱不连发 2 天；获客支柱（P1/P5）与转化支柱（P3/P4）交替；
4. 每条内容 = 钩子（question 改写）+ 要点（insight 前 3 条）+ 金句（quote）+ CTA（表内指定）；
5. 数据回流：每周记录 各条互动数 → 淘汰低互动选题式，高互动式进 加倍池。
