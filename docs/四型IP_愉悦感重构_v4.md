# 四型 IP · 愉悦感重构 v4

> 日期：2026-09-04 00:43 ｜ 依据：用户反馈「表情都是生气难过，用户天然反感；要看着开心的 IP，参考牛来/奶娃/肥嘟嘟」
> 性质：**设计哲学转向**（推翻 v3 的「人格写在脸上」，改为「人格藏进细节」）

---

## 一 · v3 为什么错（复盘）

| v3 做法 | 结果 | 错误 |
|---|---|---|
| 承重者 → 抿嘴、绷下颌、皱眉 | 生气脸 | 把「心理防御机制」直接画成了「表面情绪」 |
| 破局者 → 皱眉、锐利、不笑 | 凶脸 + 中性 | 把「坚硬」画成了「愤怒」，且靠锐利五官去中性化，越改越中性 |
| 深潜者 → 半垂眼、偏头 | 丧脸 | 把「克制」画成了「高冷丧」 |

**表情包第一定律：脸必须在 0.5 秒内产生愉悦感。** 人格是第二眼、第三眼的事——藏在动作、道具、梗里。

---

## 二 · 爆火 IP 公式（牛来 / 奶龙 / 肥嘟嘟拆解）

| 共性 | 说明 | 我们照做的 |
|---|---|---|
| **脸永远讨喜** | 圆脸、大眼、笑，零攻击性 | 四型表情基准全部改成笑 |
| **道具极简** | 一个道具扛全场（肥嘟嘟的圆身体、奶龙的胖） | 山 / 壳 / 灯 / 水（已有，保留） |
| **缺点=记忆点** | 奶龙的贱、肥嘟嘟的懒 | 四型人格缺点 = 自嘲梗（见下表） |
| **情绪外放夸张** | 表情幅度大，一看就懂 | 欢呼 / 偷看 / 得意举山，不做微表情 |
| **色彩明快** | 高饱和点缀 | 色板不变，光感更亮 |

## 三 · 新公式

```
脸 = 愉悦（大圆眼 + 笑 + 腮红，四型统一，零例外）
人格 = 姿态 + 道具互动 + 缺点梗（第二眼才看到）
```

**四型「缺点 = 梗」对照表（表情包的自嘲素材库）**：

| 型 | 缺点（人格的阴影面） | 高频使用场景 | 例句 |
|---|---|---|---|
| 磐磐 | 扛上瘾、不会拒绝的憨憨 | 职场接活、被使唤 | 「行行行我来」「又是我？」 |
| 曙曙 | 咋咋呼呼、说干就干 | 冲动下单、立flag | 「冲！」「明天一定早睡」 |
| 汀汀 | 操心老母亲、管太多 | 关心朋友、唠叨 | 「多喝热水」「吃饭没？」 |
| 潜潜 | 社恐、说消失就消失 | 躲消息、不想出门 | 「我先跑了」「在吗（不敢回）」 |

**去中性化的新解法**（曙曙专项）：不靠锐利五官，靠**萌系女性元素**——高马尾 + 碎发 + 大圆眼 + 长睫毛 + 腮红 + 小虎牙。可爱和英气不冲突，肥嘟嘟系 IP 全是圆脸。

## 四 · 四型新设定

### 磐磐 v2 ——「憨厚扛山」（紧→憨）

| 项 | 设定 |
|---|---|
| 脸 | 圆圆大眼笑成月牙，憨厚咧嘴笑，脸颊圆润带腮红 |
| 姿态 | **把发光小山高高举过头顶，得意地笑**——「看，我扛得住！」 |
| 体态 | 圆滚滚厚实小身材，站得稳稳的 |
| 人格藏在 | 山真的很重（他其实被压得矮半截，但还在笑） |

### 曙曙 v3 ——「破壳欢呼」（锐→燃）

| 项 | 设定 |
|---|---|
| 脸 | 大圆眼亮晶晶 + 长睫毛 + 粉腮红 + **咧嘴大笑露一颗小虎牙** |
| 发型 | 深红棕高马尾 + 一缕俏皮碎发，发间火星点像小烟花 |
| 姿态 | **从裂壳里跳出来，双臂张开欢呼**——破壳 = 新生的庆祝 |
| 人格藏在 | 壳的裂缝很大（她是真的不管不顾跳出来的） |

### 汀汀 v2 ——「递灯」（微调，原版已接近）

| 项 | 设定 |
|---|---|
| 脸 | 眯眼笑得更开心，腮红 |
| 姿态 | **双手把灯往镜头方向递**，像分享温暖，灯里小人也挥手 |
| 人格藏在 | 灯比她的脸亮（忘我细节保留） |

### 潜潜 v2 ——「躲猫猫」（丧→俏）

| 项 | 设定 |
|---|---|
| 脸 | 又大又亮的圆眼，眼里映星光，淡腮红，**害羞又俏皮的笑** |
| 姿态 | **躲在贝壳边缘后只露半张脸偷看**，一只手扒着壳沿——玩捉迷藏 |
| 人格藏在 | 露出来的那半张脸是笑的（想被找到，嘴上不说） |

## 六 · 验收标准（v4）

| 检查项 | 标准 |
|---|---|
| 0.5 秒测试 | 第一眼是否想笑 / 觉得可爱？任何一张「不高兴」即废 |
| 人格测试 | 遮住脸只看姿态，能否分出谁是谁？（举山 / 破壳 / 递灯 / 躲壳） |
| 缺点测试 | 能否一句话说出他的"毛病"？（憨 / 咋呼 / 操心 / 社恐） |
| 性别测试（曙曙） | 遮住身体只看脸，能否认出是女孩？ |
| 系列测试 | 四张并排 = 同一画风下的四个朋友，不是同一个人的四种心情 |
