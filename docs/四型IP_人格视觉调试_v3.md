## 二 · 磐磐（男阳·承重者）视觉处方

### 人格内核（知识库原文提炼）

- 用"扛"代替"说"——行动即存在，存在即责任
- 隐藏恐惧：无能 = 不被爱，所以必须永远强大、永远正确
- 通过被需要确认价值——"如果我不扛了，我还是谁？"
- 被触及时：向外行动，用"我必须更强更正确"盖过恐惧
- 关系：保护者/给予者位置，很难开口要

### 视觉转译（把"承重"画在脸上）

| 人格特征 | 视觉处征（要加的） |
|---|---|
| 用扛代替说 | **嘴唇抿成一条直线，唇线紧闭**——话都咽回去了 |
| 永远强大正确 | **下颌线收紧、咬肌微绷**——在用力 |
| 信任壁垒 | **眉压眼、眉眼间距近、眉尾微下压**——防御，不舒展 |
| 行动即存在（常年负重） | **肩膀端起、脖子微缩、身体微微前倾** |
| 扛不住一句"你也可以脆弱" | **眼下有极淡阴影、眼尾微红**——疲惫但不允许自己倒 |
| 保护者 | 身形厚实，肩宽明显大于头宽 |
| 扛的是责任不是快乐 | **不看镜头，视线略低** |

### 要删掉的旧特征
❌ 平静温和的微笑 ❌ 舒展的眉眼 ❌ 放松的坐姿

### 新 prompt（即梦智能参考，上传磐磐定妆照，人物长相维度 85-95）

```
保持这个角色的发色、金砂云纹、毛衣、暖金山岩环和发光小山不变，只调整面部表情和身体姿态：
他的嘴唇紧紧抿成一条直线，下颌线收紧，咬肌微微绷起，眉头微锁、眉尾下压，眼神不看镜头而是略微低垂，眼下有极淡的疲惫阴影，眼尾微微泛红。肩膀端起、脖子微缩、上身略往前倾，双臂把发光的小山死死抱在胸前，手指关节用力。
表情是"在忍、在扛、不允许自己倒下"，不是平静也不是微笑。
Q版扁平化可爱插画风格，与参考图画风完全一致，温暖米色背景，画面中无文字
```

## 三 · 潜潜（男阴·深潜者）视觉处方

### 人格内核

- 敏感 + "男人不该这样"的双重挤压
- 过度思考代替行动——怕做错、怕被评判
- 最深恐惧：畏惧交付——"把真心交出去，被伤害了怎么办"
- **在"渴望深度连接"和"害怕被吞噬"之间反复横跳（推和拉同时存在）**
- "你看到的冷漠，是我用尽全力控制自己不要陷进去的样子"
- 敏感是天线，不是缺陷

### 视觉转译

| 人格特征 | 视觉处征 |
|---|---|
| **看得最清** | **瞳孔里有细碎的水面反光**——眼睛里有内容，不是空的高光点 |
| 说得最少 | 嘴小、唇线轻、欲言又止地微张 |
| **控制自己不要陷进去** | **视线偏向一侧，不看镜头**（回避） |
| **推拉同时存在**（灵魂动作） | **一只手伸向水面想去触碰，上半身却微微后仰** |
| 双重挤压的内耗 | **脸型更瘦削、眼下极淡的青色** |
| 戴一层"阳壳" | 表面平静，**但贝壳里的水映出的倒影是蜷缩的** |
| 敏感是天线 | 发丝与指尖有细微的光点，像在接收信号 |

### 要删掉的旧特征
❌ 呆萌的大眼睛 ❌ 正面直视 ❌ 纯粹的放松感

### 新 prompt（上传潜潜定妆照，人物长相维度 85-95）

```
保持这个角色的发色、星点发纹、毛衣、深青贝壳和壳内的水不变，只调整面部表情和身体姿态：
他的脸型更瘦削、下颌线清晰，眼下有一层极淡的青色。眼睛半垂着，视线偏向一侧不看镜头，瞳孔里映着细碎的水面反光。嘴唇很轻地抿着，像想说什么又咽回去。
身体姿态：一只手的手指伸向水面想要触碰，但上半身却微微向后仰——像想靠近又不敢靠近。
贝壳里的水面上，他的倒影是蜷缩着的，比他本人的表情情绪更浓。
发丝和指尖有细微的光点在轻轻感应。
表情是"在观察、在克制、在拼命控制自己不要陷进去"，不是发呆。
Q版扁平化可爱插画风格，与参考图画风完全一致，浅蓝背景，画面中无文字
```

## 四 · 曙曙（女阳·破局者）视觉处方（去中性化）

### 人格内核

- 天生反叛——社会期待她柔软，她的内核是直面和行动
- 用"搞定事情"证明价值——"我能行，我不需要任何人"
- 隐藏恐惧：**示弱 = 被吞噬**
- **她不是"太强势"，是太早学会了自己扛；坚硬不是攻击，是防御**
- 讨厌被当成"该温柔一点"的女人
- 在"我不需要任何人"的铠甲和"其实我也需要被接住"之间反复横跳

### 视觉转译（去中性化 ≠ 变柔，是变「飒」）

| 人格特征 | 视觉处征 |
|---|---|
| 女性身份 vs 阳性内核 | **明确的女性轮廓 + 英气五官**（保留女性特征，强化英气） |
| 直面和行动 | **身体前倾、重心在前**（随时要冲出去） |
| **坚硬是防御** | **下巴微抬、嘴唇紧闭**——防御姿态，不是笑 |
| 用搞定事情证明价值 | **眼神锐利、聚焦、直视镜头，带攻击性** |
| **铠甲 ↔ 渴望被接住** | **一手用力撑壳沿（硬），另一只手悄悄攥着衣角（软）** |
| 天生反叛 | **眉形上扬、眉峰锐利** |
| 不是少女是战士 | **弱化婴儿肥、下颌线清晰** |

### 要删掉的旧特征
❌ **短发（中性化主因）** ❌ 圆润的脸和婴儿肥 ❌ 微笑 ❌ 纯可爱的观感

### 新 prompt（上传曙曙定妆照，人物长相维度 80-90）

```
保持这个角色的发色、火星光点发纹、绯红毛衣、裂开的茧壳和壳内暖光不变，只调整发型、五官和姿态：
发型改为深红棕色的高马尾（或及肩的飞扬长发），不是短发。
五官：眉形上扬、眉峰锐利，眼型偏长、眼角微微上挑，下颌线清晰、弱化脸颊的圆润感，唇形明确。保留女性化的面部轮廓和身形线条。
表情：下巴微微抬起，嘴唇紧闭不笑，眼神锐利地直视镜头，像在说"别小看我"。
姿态：身体前倾、重心在前，一只手用力撑住壳的裂缝边缘、指节绷紧，另一只手悄悄攥着自己的衣角。
气质是"少女战士"——有女性的美感，但骨子里是硬的，坚硬的底下是防御不是攻击。
Q版扁平化可爱插画风格，与参考图画风完全一致，浅粉背景，画面中无文字
```

## 六 · 验收标准（重出后逐条核）

| 型 | 一句话验收 | 具体看哪里 |
|---|---|---|
| 磐磐 | "看得出来他扛得很重，但绝不松手" | 嘴是否抿紧、下颌是否绷、肩膀是否端着、眼神是否不看镜头 |
| 潜潜 | "看得出来他在看，但不想让你知道他在看" | 瞳孔里是否有水光、视线是否偏开、是否一手想碰水身体却后仰 |
| 曙曙 | "这是个不好惹的女孩" | 是否长发、眼神是否锐利、是否有攥衣角的软细节 |
| 汀汀 | "她把自己忘了" | 灯是否比脸亮、眼神是否在灯上 |

**反面检查**：如果三张图放在一起，你还能觉得"这三个人性格差不多"，就是没调到位——四型并排应该像四个完全不同的人，只是画风相同。
