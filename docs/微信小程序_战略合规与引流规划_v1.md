# 微信小程序版 · 战略/合规/流量规划 与 三平台引流方案 v1

> 日期：2026-08-30 ｜ 前提：网页版先行（已完成开发待部署），小程序为第二阶段
> 一句话：**小程序不是网页移植，而是「合规子集 + 微信社交流量引擎」**——`compliance: web+mini` 字段体系早已为此预埋。

---

## 一、战略：双端分工与启动节奏

| | 网页版 | 小程序版 |
|---|---|---|
| 定位 | 完整版/自由港：全量知识（含深水、情与欲等 web-only 内容） | 合规版/转化器：仅 L1–L3 合规子集 |
| 角色 | 内容护城河、SEO 入口、迭代试验田 | 裂变引擎、视频号承接、远期付费闭环 |
| 约束 | 无 | 微信审核体系、类目限制、ICP 备案 |

**启动节奏**：网页版上线 → 跑 2–4 周拿到基础数据（完成率/分享率/高频知识卡）→ 用数据校准后开做小程序（复用同一套数据层，前端用 web-view 或原生重写二选一，建议**原生重写核心三页**（测评/结果/问一问）以过审且体验好）。

**主体路线（用户 08-30 拍板）**：**个人主体试水**（用户为执业律师，受兼职限制无法注册公司/个体户）。个人主体边界与对策：
- 可做：工具类目（工具>效率）注册、ICP 个人备案（非经营性）、**流量主**（累计 UV ≥1000 后可开广告位，个人主体允许）——这是个人主体唯一的变现通道；
- 不可做：微信支付（远期变现需换路径：①引流至公众号付费专栏/知识星球 ②届时若有合作方可承接主体再升级）、教育类目大部分子类（需企业资质）、「心理」类目（本就因资质规避）；
- ICP 备案走个人非经营性备案（1–2 周）；
- 名称：个人主体名称不得含企业化/行业误导词，「阴阳人格手记」类文化工具向名称可通过性高；
- ⚠️ **律师身份隔离提示**（用户为执业律师，需注意执业规范）：产品运营与律师执业身份**彻底分离**——① 社媒账号（小红书/抖音/视频号）不以「律师」认证或冠名做测评引流内容（律协对律师业务营销有规范，测评引流不属法律服务营销，混用身份有执业风险）② 站内免责声明以「本站为非官方知识整理」口径，不出现律所/律师署名 ③ 产品合同（远期如与 UP主 合作）再以律师身份把关。

## 二、合规红线清单（生存边界）

| # | 红线 | 后果 | 本项目处理 |
|---|---|---|---|
| 1 | **迷信算命类**（占卜/运势/缘分预测/塔罗/前世今生） | 清朗专项清理对象，一票封禁 | 「阴阳」易被误判 → 全站「能量/自我认知」口径；**绝不用**「测缘分/命中注定/你们是天生一对」话术；配对报告文案写「能量互补参考」不写「配对指数 destiny」类表述 |
| 2 | **心理诊断/治疗宣称** | 「心理」类目需专业资质，宣称诊疗直接拒审 | 结果页固定免责行：「本测试为自我探索工具，不构成心理评估或医疗建议」；不用「治愈/疗愈你/诊断」字样（「疗愈」一词在知识卡原文里高频出现，**小程序版标题与 UI 文案规避，正文引用原文可保留但页面级标题不用**） |
| 3 | **涉性内容** | 零容忍 | B714 情和欲、性爱分离、双火苹果等卡一律 `web-only`；上线前跑 compliance 字段全量审计脚本 |
| 4 | **性别对立** | 三平台都打击「挑动男女对立」 | 讲能量不讲性别优劣；男阴/女阳「错位型」叙事是反刻板印象的加分项，主动用它对冲 |
| 5 | **诱导分享**（分享解锁/强制转发） | 违规处罚 | 设计保持「测完自然获得分享选项」；配对邀请是自愿动作不是解锁条件 |
| 6 | **无审核 UGC** | 评论功能必须接内容安全接口 | P2 的 UGC 征集上线前必须接 `msgSecCheck`；MVP 阶段不做 UGC 最稳 |
| 7 | **类目错报** | 类目与内容不符会被驳回/下架 | 类目候选：工具>效率 / 教育>学习辅导（个人主体可办）；**避开**「心理」类目（需资质）与「占卜」相关类目；名称避免「测算」「命理」字样，建议「阴阳人格手记」「能量内核测评」方向 |
| 8 | **数据隐私（个保法）** | 收集手机号/身份信息需隐私协议+接口声明 | 我们只存 localStorage 等价物（本地存储），不收集个人信息 → 隐私协议写明「数据仅存于用户设备」即可，这是最轻合规路径 |
| 9 | **名称与头像审核** | 与已有IP重名/侵权被驳 | 「都是一些小问题」UP主相关名称不可擅用；用自有品牌「阴阳人格」，页脚保留内容来源声明 |

## 三、微信生态流量逻辑（什么最容易获得流量）

微信小程序的流量来源按性价比排序：

1. **社交裂变（最高性价比）**：分享图片卡 → 群聊/好友点开 → 带参测试 → 配对报告 → 二次分享。微信的分配逻辑奖励「被转发的小程序」；**结果页图片卡 + 双人配对报告**是两个裂变原件（P0 项，网页版先做，小程序复用）；
2. **视频号联动（官方最扶持）**：视频号直播/短视频可挂小程序组件——这是微信唯一官方支持的「内容→小程序」直通车。视频号发四型解读短视频 → 挂「测一测」→ 无缝转化；
3. **微信搜一搜 SEO**：小程序名称/简介/页面可被搜一搜索引——「人格测试」「阴阳人格」「能量类型测试」等词的布局；知识卡页面标题化（每张卡一个可分享页）；
4. **群运营**：双生/成长主题微信群是种子池——小程序卡片在群里的打开率远高于 H5 链接（信任度高、即点即用）；
5. **附近/推荐位等**：个人主体基本无缘，不考虑。

**反面清单（别指望的流量）**：小程序没有「发现页流量红利」给工具类；朋友圈分享小程序卡片受限（只能海报码）；跨 App 导流（抖音→微信）有墙。

## 四、三平台引流方案

### 总原则
- **一个钩子贯穿全平台**：「20 道人生选择题，测你是哪种能量内核」+ 结果关键词（承重者/破局者/连接者/深潜者）；
- **平台分工**：抖音=流量池（最大盘、做爆款）、小红书=精准池（女性/情感人群、做转化）、视频号=私域池（直接挂小程序、做闭环）；
- **导流合规**：抖音严禁明示微信导流（用「主页/评论区暗语+昵称谐音」）；小红书严禁直接放链接（用群聊/瞬间/薯店路径，最稳是引导搜索公众号）；视频号可直挂。

### 小红书（精准转化池）
- **人设**：「研究阴阳人格的观察者」，笔记人格 = 冷静分析 + 情感共鸣，避免大师感；
- **内容矩阵**（每周 3–4 篇）：① 影视角色四型拆解（《甄嬛传》谁是承重者/深潜者——自带搜索流量）② 场景共鸣型（「为什么你总在关系里反复确认 Ta 在不在乎——可能你是连接者」）③ 干货型（四型速查图、配对互补表——图卡设计成可保存的「资料感」）④ 争议话题型（「男阴是最压抑的群体」——注意用反刻板印象框架写，不搞对立）；
- **钩子设计**：评论区置顶「完整的 20 题测评我放在公众号 XX 了」→ 公众号菜单/文章挂小程序码；笔记本身用「测过的人都说准」类晒图（结果页图片卡）养信任；
- **关键词布局**：标题埋「人格测试」「阴阳人格」「MBTI 平替」——蹭 MBTI 搜索量是合规且有效的策略；
- **节奏**：先发 10 篇测内容方向（哪类互动率高）→ 加大该类投入。

### 微信视频号（私域闭环池）
- **独特优势**：可挂小程序组件，是三平台唯一「内容→产品」无摩擦路径；
- **内容**：① UP主语料切片二创（1–3 分钟竖屏，字幕大字，选题=问答卡同款理论命题：「面对冲突为什么阴逃阳战」）② 直播连麦解读（UP主受众迁移）③ 图文轮播（知识卡直出）；
- **节奏**：短视频挂「测一测」组件 + 评论区置顶；每周 2–3 条 + 每两周一场直播；
- **合规**：视频号内容同样受微信审核，口径与小程序一致（能量/自我认知，不算命不诊疗）。

### 抖音（流量放大池）
- **打法**：强钩子短视频——前 3 秒痛点（「为什么你扛住了全世界，却扛不住一句『你也可以脆弱』？」）→ 四型概念 30 秒讲透 → 结尾引导（「完整版测试在主页」）；
- **导流路径**：抖音禁止明示微信——用「主页签名谐音/粉丝群/小程序（若上抖音小程序另议）」；**最现实路径**：抖音做品牌声量与私域沉淀（粉丝群），群公告引导至公众号/小程序；
- **内容复用**：与视频号同素材分发（注意去水印、改封面标题防查重）；
- **爆款选题库**（从知识卡直接来）：① 「四个字看穿你对象：承/破/连/潜」② 「MBTI 测不准的人，试试这个」③ 「女阳不是强势，是太早学会自己扛」④ 「男阴的高冷，是控制自己不要陷进去」。

### 平台协同节奏（月度）
```
第 1–2 周：小红书 10 篇试水 + 视频号 4 条 + 抖音 4 条（同一钩子不同表达）
第 3–4 周：复盘各平台数据 → 集中打最高互动内容类型；视频号开始试播 1 场
持续：结果页图片卡收集用户晒图（授权后）做 UGC 素材回流
```

## 五、小程序落地路线图

| 里程碑 | 内容 | 前置 |
|---|---|---|
| MP0 | ICP 备案启动 + 主体注册 + 类目/名称预审 | 立即（备案周期最长） |
| MP1 | 原生重写三页（测评/结果/问一问）+ 图片卡 + 配对邀请，compliance 审计脚本跑全量数据 | 网页版数据 2–4 周 |
| MP2 | 视频号挂载 + 搜一搜 SEO + 群裂变工具（带参邀请） | MP1 过审 |
| MP3 | 数据看板（自有统计）+ 复测对比 + 每日一问 | MP2 上线 |
| 远期 | 个体户升级 + 支付（进阶报告/知识手册）+ UGC（msgSecCheck） | 数据验证 |

## 六、决策点（需用户拍板）

1. 主体路线：个人试水 vs 直接个体户；
2. 小程序名称方向：「阴阳人格手记」/「能量内核测评」/ 其他；
3. MP1 范围确认：三页原生重写（约等于重做前端，工作量 ≈ 网页版 60%）vs 先用 web-view 套壳试水（快但体验与过审风险差）；
4. 引流启动顺序：小红书先 vs 视频号先（建议：视频号与小程序同步、小红书先行蓄水）。
