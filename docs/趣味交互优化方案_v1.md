# 阴阳人格 · 趣味交互优化方案 v1

> 性质：纯设计研究文档。只读现状（index.html 共 3022 行），产出「愉悦体验」维度的诊断与可实施建议。**不修改任何代码文件。**
> 定位：与已有三份视觉方案互补不冲突——**视觉方案解决「看起来像什么」**（晨昏光谱、印章视觉、字阶与 token），本方案解决**「摸起来、点下去、等一会儿、做完之后」是什么手感**。领域划分：视觉精致化＝看；测试页叙事＝听故事；本方案＝玩。所有建议遵循「守卫式追加」：不动现有 DOM 结构、函数签名、数据字段；动画只用 `transform/opacity`；不动 31MB 语料检索主路径。
> 目标调性：像在纸上盖一枚好印章——克制、确定、有分量。愉悦来自「被温柔接住」的确定感与「偶尔的小彩蛋」，不靠浮夸特效与音效轰炸。

## 二、设计原则（5 条）

1. **一切确认，皆印章**：把「选中 / 完成 / 已读 / 达成」全部翻译成「落印」这一种手势。印章家族（`.seal`）已是品牌视觉核心，让它在交互层承担「确认」语义，视觉与手感共用一套语言。
2. **一次只给一个惊喜**：每个关键时刻（答完题、完成测评、精确命中、达成连续）只保留一个主要动效，其余静默。惊喜是稀缺资源，滥用即失效。
3. **手感快于眼睛**：反馈延迟 ≤120ms；动画只用 `transform/opacity`（不触发布局重排）；长时间动画遵守 `prefers-reduced-motion`（全站已有全局关闭，新动效一律归入该开关）。
4. **守护式追加**：所有 JS 新增一律用「事件委托 / MutationObserver / boot 后一次性 IIFE」实现，不修改任何现有函数体；CSS 一律「新增规则 + 新增类」，不改旧值。
5. **悦而不吵**：声音默认关闭、震动可感知即止；文案用成语/诗意象点题，克制不堆砌 emoji；国风哲思感优先于「好玩」。

## 三、交互令牌与动效语言

### 3.1 新增动效令牌（在 `:root` L13-29 之后追加，只加不改）

```css
:root{
  /* —— 趣味交互 v1 新增：动效令牌 —— */
  --dur-ms:120ms;                 /* 按压/涟漪：短促 */
  --dur-q:180ms;                  /* 选项/卡片切换：轻快 */
  --dur-m:280ms;                  /* 展开/翻篇：中等 */
  --dur-seal:420ms;               /* 落印/盖章：仪式 */
  --ease-seal:cubic-bezier(.34,1.56,.64,1);   /* 落印回弹：先压后弹 */
  --ease-gentle:cubic-bezier(.25,.8,.35,1);   /* 普通动效 */
  --stamp-x:-2deg;                /* 印章落印的惯常倾角（沿用 ±2° 规范） */
}
```

### 3.2 「落印」统一动效原语（一次定义，处处引用）

```css
@keyframes sealStamp{               /* 从悬空到盖定：放大→回落→微倾定格 */
  0%{ transform:scale(1.45) rotate(0deg); opacity:0; }
  55%{ transform:scale(.94) rotate(var(--stamp-x)); opacity:1; }
  75%{ transform:scale(1.05) rotate(var(--stamp-x)); }
  100%{ transform:scale(1) rotate(var(--stamp-x)); }
}
@keyframes inkBloom{                /* 印泥洇开：墨迹扩散渐隐 */
  0%{ opacity:.5; transform:scale(.4); }
  100%{ opacity:0; transform:scale(1.6); }
}
```

**落印触发原则**：只对「一次性状态翻转」（首次选中、完成、达成）播放；状态来回切换（如 tab、筛选）只用 `.3.1` 的短时长过渡，不播落印。

## 四、分级方案

### P0 — 立即可落地（纯 CSS / 轻量 JS，零数据改动，低风险）

> 全部为「新增 CSS 规则 / 事件委托追加」，不改任何现有函数体。

#### P0-1 选项「盖章」选中反馈（A2/A3）

- **改动位置**：`.q-opt`（L272-276）；`pickOpt()` 已有事件流（L2648-2655），用事件委托追加。
- **实现**：
  ```css
  .q-opt{ position:relative; }                                   /* 已可定位 */
  .q-opt.selected::after{                                        /* 落一枚小方章 */
    content:'已' ;
    position:absolute; right:14px; top:50%; margin-top:-13px;
    width:26px; height:26px; display:flex; align-items:center; justify-content:center;
    font-family:var(--serif); font-size:12px; color:#FFF6F0; border-radius:3px;
    background:radial-gradient(130% 130% at 30% 22%,#C85F4C,#B5483A 48%,#9A382D);
    transform:rotate(-2deg); animation:sealStamp var(--dur-seal) var(--ease-seal) both;
  }
  .q-opt.selected::before{                                       /* 印泥洇开的一圈 */
    content:''; position:absolute; right:22px; top:50%; width:30px; height:30px;
    margin:-15px 0 0; border-radius:50%;
    background:radial-gradient(rgba(181,72,58,.35),transparent 65%);
    animation:inkBloom .5s ease-out both;
  }
  ```
  JS（守卫式，boot 后追加一次）：`document.addEventListener('click',e=>{const o=e.target.closest('.q-opt');if(o)o.classList.remove('stamp');void o.offsetWidth;o.classList.add('stamp');})`。无需改 `pickOpt`，`.selected` 已有即可。
- **风险与回归点**：`.q-opt` 是 `<button>`，`::before/::after` 需确认无冲突（当前未占用）；`content` 用「已」字符合印章规范（色底白字单字）；回归测「上一题再下一题」的选中重绘。

#### P0-2 全站按压梯度化（A1）

- **改动位置**：在 L631 统一 `:active` 之后**追加**覆盖规则（不改 L631）。
- **实现**：按语义分三档，均只动 `transform`：
  ```css
  .btn-cta:active,.btn:active{ transform:scale(.96); }                 /* 主操作：略沉 */
  .q-opt:active,.gcard:active{ transform:scale(.985) translateY(1px); } /* 选择项：下压入纸 */
  .plate:active,.qcard:active,.s-corpus:active,.pair-card:active{ transform:scale(.99); } /* 卡片：轻点 */
  ```
- **风险与回归点**：与 L631 同特异性覆盖，纯追加；需确认 `transition` 已含 `transform`（各卡片均已有）。

#### P0-3 进度条「墨迹前行」（C1）

- **改动位置**：`.progress-fill`（L254）。
- **实现**：保留宽度过渡，追加墨迹光点，只动 `transform`：
  ```css
  .progress-fill{ position:relative; overflow:hidden; }
  .progress-fill::after{ content:''; position:absolute; top:0; bottom:0; left:-20px; width:18px;
    background:linear-gradient(90deg,transparent,rgba(255,246,240,.75),transparent);
    animation:brushGlide 2.2s var(--ease-gentle) infinite; }
  @keyframes brushGlide{ from{ transform:translateX(0);} to{ transform:translateX(120vw);} }
  ```
  章节转场页的 `.ch-ticks`（L266-268）保留不动——那是「里程碑」，答题中走墨迹，章节间走刻度，两种节奏已分开。
- **风险与回归点**：伪元素不参与宽度的 `transition`，无性能风险；`prefers-reduced-motion` 下随全局关闭。

#### P0-4 知识卡「展开」仪式感（A5）

- **改动位置**：`.qcard.open`（L198）/ `.qcard-body`（L204-205）。
- **实现**：展开完成态增加「钤印已阅」小标记——`.open` 时在卡片右上浮现一枚迷你方章：
  ```css
  .qcard{ position:relative; }
  .qcard.open::after{ content:'已览'; position:absolute; right:12px; top:12px;
    font-family:var(--serif); font-size:10px; color:#8A5A1F; letter-spacing:.1em;
    border:1px solid rgba(212,165,116,.55); border-radius:3px; padding:1px 6px;
    background:rgba(212,165,116,.08); animation:sealStamp var(--dur-seal) var(--ease-seal) both; }
  ```
  注意与 `.qcard-q::before` 序号章（L201）并存不冲突；`.open` 会持久保留，`::after` 仅在展开态出现，天然表达「这条我看过了」。
- **风险与回归点**：右上角是否遮挡 `.cat-badge`（L187 区）——建议 `top:12px;right:12px` 与徽标同排，回归看首张卡；收起后自动消失，无需清理。

#### P0-5 页面切换「翻篇」过渡（A4）

- **改动位置**：`.page` 各 section（L693/822/866/871/887/897）；`route()` 由 hashchange 驱动，重新渲染即重放动画。
- **实现**：
  ```css
  .page{ animation:pageTurn var(--dur-m) var(--ease-gentle) both; }
  @keyframes pageTurn{ from{ opacity:0; transform:translateY(10px);} to{ opacity:1; transform:none;} }
  ```
  只动 `opacity/transform`；`route()` 每次替换目标 section 的 innerHTML 时会自然重触发（不改 `route` 函数）。
- **风险与回归点**：若某页重渲染不换 section 会导致动画不重放（可接受，不强制）；测试页 `testBox` 内部多步渲染（L2611/2639）不触发 `page` 级动画，恰好不会打断答题节奏。

#### P0-6 空态 / 加载态 / toast 趣味文案（D1-D3）

- **改动位置**：仅替换字符串字面量，不动数据结构。守卫式做法：新增 `LANG` 文案映射对象 + 一个 `txt(key,fallback)` 读取函数，对**新增文案位**直接调用；对现有 `toast()`（L1870）内部做一次「已知消息→趣味消息」映射，不改任何调用点签名。
- **建议文案**（国风语境，保持克制）：
  | 场景 | 现值 | 建议值 |
  |---|---|---|
  | 测试卷加载 | 「题卷加载中…」(L2508) | 「笔墨备好，正在铺纸…」 |
  | 语料加载 | 「正在加载语料库…」(L2228) | 「正在翻检 500+ 卷宗，稍候…」 |

  | 我的·无历史 | 「还没有测评记录」(L2316) | 「第一枚印章，等你落笔——去测一测。」 |
  | 无续答进度 | 「没有可续答的进度」(L2525) | 「书案空空，尚未落墨——开一局新卷吧。」 |

### P1 — 需少量 JS 或用户确认

#### P1-1 首次使用引导趣味化（B4）

- **改动位置**：`boot()` 之后追加 IIFE；首页 hero `.hero-seals`（L759-763）。
- **实现**：`localStorage` 读 `yy_seen` 标记；首次进入时给 `.hero-seals` 加 `.first-seen` 类，两枚印章做「并拢轻碰」入场（约 1s，一次播完），并在 CTA 下方追加一条 12px 引导小字（守卫式 append，不入现有模板）：「初次见面——从'测一测'开始，认识你的能量内核。」再次进入不重放。
- **风险与回归点**：只写 `yy_seen` 一个新 key，不动现有 key；引导小字用 `.first-tip` 类可被后续视觉方案统一样式。

#### P1-2 连续访问成就彩蛋（B2）

- **改动位置**：成长课题页 `renderHeal()` 输出之后；新增 `yy_streak` / `yy_lastday` 两个 key。
- **实现**：boot 后 IIFE 维护连续天数——`dateNum()`（L1031 复用）与 `yy_lastday` 差值：+1 天续链，断档清零；在 `#healBox` 顶部守卫式注入一行「修行 · 连续 N 天」印章条；N∈{3,7,14,30} 时追加 `seal-stamp` 落印 + toast（映射表，P0-6 复用）：「三而成习，已成惯性」「七日之期，修已有痕」。
- **风险与回归点**：仅新增 key 与 DOM 注入，不触碰 `renderHeal` 内部；多端（桌面/移动）同日刷新不重复 +1。

#### P1-3 搜索「命中」反馈（B3）

- **改动位置**：`runSearch()` 渲染之后（L2281 `out.innerHTML=html` 之后守卫式追加）。
- **实现**：渲染后检测——若 `qaHits.length===1` 且第一条 `c.question` 与 `q` 相等（或互含），给该 `.qcard` 加 `.perfect-hit`，播放 `sealStamp` 落印 + toast「正中此问」；若 `qaHits.length>0` 给首卡加轻微 `hit-glow`（一次闪光，opacity 动画）。`hl()` 高亮（L2273）已有，叠加不冲突。
- **风险与回归点**：匹配判定用「包含」宽松阈值，避免几乎命中但不同词的误报；不阻塞 31MB 语料注入主路径（在 `runSearch` 同步渲染段之后执行，语料部分保持原逻辑）。

#### P1-4 测试进度「人生旅程行至何处」（C1）

- **改动位置**：`.progress-meta`（L255）右格「第 x/20 题 · 第N章」（L2639-2640 模板）。
- **实现**：守卫式——`showQuestion()` 完成后读取 `.progress-meta span:last-child` 文案，将「章名」替换为旅程化表述：`第N章 → '行至：'+ch.title`（ch.title 已含「小时候的家」等）。为不修改 L2639 模板，用 boot 后一次事件委托 `document.addEventListener('click',…)` 检测 `#btnNextQ` 点击后 50ms 内改 `.progress-meta` 文案；或更稳：在 `showQuestion` 生成的 `.q-tag` 已有章名，仅将 meta 右格换成旅程词（如「行至·校园与少年」）。
- **风险与回归点**：只改文案字符串不碰数据；`prevQuestion` 也会刷新，委托命中任意 `.q-nav button` 即可。

#### P1-5 知识卡已读进度「阅卷章」（C2）

- **改动位置**：`.read-progress`（L577-578 / L1053）。
- **实现**：不换模板——追加伪元素：`rp-fill` 达 100% 时（P0-6 映射判断）右侧浮一枚「阅毕」小章（`animation:sealStamp`）；CSS 写法：
  ```css
  .read-progress:has(.rp-fill[style*="width:100%"])::after{ content:'阅毕'; ... }
  ```
  若顾虑 `:has` 兼容（iOS 15.4+ 才支持），降级方案：守卫式 JS 每 30s 检查一次 `rp-fill` 宽度并加 `.done` 类，命中时追加落印。
- **风险与回归点**：`.read-progress` 为 JS 重渲染节点，类会被冲掉——故用「父级 `:has`」或「观察 + 类加在 `.read-progress` 父容器」；零数据改动。

#### P1-6 每日一签（D4）

- **改动位置**：复用 `renderHomeDaily` 的 `dateNum()%pool` 机制（L1031-1036），新增「今日一签」卡，置于 `#homeDaily` 之后（守卫式注入）。
- **实现**：从 `corePool()` 里取当日卡，抽 `quote` 字段（无则取 `question`）作签文；模板为印章 + 竖排签文 + 「解签 → 看完整卡」按钮（复用 `goQaCard`，不加新函数）：
  ```
  ┌─────────────┐
  │ [章] 今日一签 │
  │ 「人前一个样，  │
  │   独处另一个样」 │   ← 抽自现有 quote 数据
  │  解签 →       │
  └─────────────┘
  ```
  签文数据零新增，全部来自现有 `QA` 字段。
- **风险与回归点**：注入位置在 `#homeDaily` 后，与 `#homeLastResult`（L772）顺序需人工确认；`quote` 缺失兜底 `question`，空态不渲染。

#### P1-7 微震动（感官 · 降级标注）

- **改动位置**：全局事件委托（boot 后一次）；`pickOpt` / 章节转场 / 结果页均由既有 DOM 事件可捕获。
- **实现**：
  ```js
  var vib=function(ms){ try{ if(navigator.vibrate) navigator.vibrate(ms); }catch(e){} };  // iOS 无此 API → 静默跳过
  document.addEventListener('click',function(e){
    var o=e.target.closest('.q-opt'); if(o){ vib(8); return; }        // 选中：轻轻一叩
    if(e.target.closest('.btn-cta')){ vib(12); }
  });
  /* 完成测评：showResultFlow 由点击「看我的结果」触发 → 在 result-wrap 出现时 vib([16,40,24]) */
  ```
  系统级降级：iOS Safari 不支持 `navigator.vibrate`；Android 用户可在系统设置关闭震动——函数内 `try/catch` + 能力检测即完整降级，无需开关。
- **风险与回归点**：震动强度控制在 8-24ms 区间（「可感知的轻叩」，非「报警式」）；勿对滚动、hover 触发。

#### P1-8 长按 / 双击彩蛋（B5）

- **改动位置**：首页晨昏轮 `.wheel-wrap`（L697）；顶部品牌 `.brand-seal`（L679）。
- **实现**：事件委托 + 计时：
  - 长按晨昏轮 600ms（`touchstart` 起计，`touchmove`/`touchend` 取消）→ 晨昏轮加 `.wheel-tap`，SVG 做一次「轴心轻转 6° 再回正」（transform 动画，不影响 60s 自转的 `wheel` 类——两者作用不同元素或叠加 transform-origin 分开）→ toast「晨昏轮转，昼夜相抱」。
  - 双击品牌 seal（两次 click 间隔 <300ms）→ 印章 `sealStamp` + toast 映射「阴阳互根，负阴抱阳」。
- **风险与回归点**：长按需防误触——`touchmove` 位移 >10px 即取消；桌面端 `mousedown` 与 `touchstart` 分路监听避免双触发；不拦截默认行为（图片保存/复制不受影响）。

## 附：一句话总结

愉悦体验的抓手是**把全站已有的「印章语言」从视觉搬进手感**：选项选中是落印、测评完成是盖印、卡片展开是钤印、已读进度是阅毕章——惊喜只留给「完成测评、精确命中、连续访问」三处，声音震动默认哑火、文案克制点题，所有实现一律守卫式追加，P0 八项加起来不改任何现有函数体，即可让「点下去」这件事从「变色」变成「盖章」。
