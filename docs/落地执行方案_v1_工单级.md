## B1 · 前端工单一：接线 + 阅读体验 + 埋点

- `<script src="data/qa_core.js">` 引入（顺序：data_qa → qa_clips_new → qa_core，core 最后 concat 进 QA 池）；**合并去重规则：同 kpId 时 QA_CORE 覆盖旧卡**（实现：concat 后按 kpId 反向去重，core 优先，无 kpId 的科普卡全保留）；
- `qaCardHtml()` 渲染升级：`insight` 存在时渲染为带序号要点列表（视觉 Agent 的新样式类，若类名变动以最终 CSS 为准）；`evidence` 渲染为「▶ 语料佐证」折叠区（默认收起，与旧 `answer` 字段兼容：无 insight 的卡走旧渲染）；

- **验收**：搜索「四型」命中 q-y0-02-01 且 insight 六条全渲染；旧卡（无 insight）显示不回归；问一问列表 core 卡排前。

### W-F2 三档阅读 + 镜子 + 卡间导航 + 阶分组
- 卡片头部三档切换（tab）：**速览**（answerBrief+quote）/ **读懂**（insight 要点，默认档）/ **溯源**（evidence 原文+B站直跳）；实现为卡内 tab，状态存 data-attr 不刷新；

- **验收**：完成一次测评+开一张卡+搜一次词后，evlog 中 5 类事件齐全且字段正确；本地模式零外部请求。
