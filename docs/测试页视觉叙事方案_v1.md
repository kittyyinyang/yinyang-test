## 一、叙事框架：五幕人生旅程

### 1.1 核心创意一句话

> **「20 道题不是问卷，是你把人生重走了一遍——从白天的家门，走到深夜的房间。」**

用户完成一次测试 ≈ 走完一段「一日的光」，而这恰好就是产品已有的视觉母题——**晨昏光谱**（阳=晨橙昼·动·向外，阴=暮蓝夜·深·向内）。测试流程天然是一条从「昼（阳）」滑向「夜（阴）」的光线轨迹，与人格判定同构。这就是本方案唯一的叙事主轴，**不需要发明新符号**。

### 1.2 五幕光线映射表（scene → 章节 → 视觉主题）

题卷数据里 `scene` 与 `chapter` 恰好一一对应（每章只有一个 scene），所以**章节封面与题级氛围图可以共用同一套映射，零数据改动**。

| 章 | 章节名 | scene | 题数 | 光线时相 | 一幕之题 | 主色倾向 | 意象符号 |
|---|---|---|---|---|---|---|---|
| 壹 | 小时候的家 | `family` | 4 | **晨光**（昼之始） | 「家门」 | 暖杏→晨橙 | 半开的门、晨光、攥着卷子的孩子背影 |
| 贰 | 校园与少年 | `school` | 3 | **白昼**（日照当空） | 「操场」 | 纸白→琥珀 | 跑道弧线、球、自行车、双少年剪影 |
| 叁 | 职场里的你 | `work` | 4 | **午后强光**（办公室白灯） | 「会议桌」 | 冷白→雾蓝 | 长桌、吊灯、发光的电脑屏、窗与天际线 |
| 肆 | 亲密关系里的你 | `love` | 4 | **黄昏**（昼入夜） | 「镜与双影」 | 琥珀→暮蓝 | 圆镜、相对的两把椅子、两杯水、手机屏光 |
| 伍 | 深夜独处的你 | `self` | 5 | **深夜**（夜之底） | 「凌晨房间」 | 深暮蓝→夜色 | 月光、窗与窗帘、床、发光的手机 |

三条并行的叙事线索：

1. **光线线**：晨 → 午 → 昏 → 夜。用户每过一章，天色暗一档，等于在「向内走」。
2. **场景线**：门 → 操场 → 会议桌 → 双影 → 房间。空间从「对外界敞开」一路收窄到「只有自己」。
3. **内核线**（复用题卷原有设计）：第伍章全部是 `self` 独处题，且含 dualOf 对偶题——「深夜先开口的，还是小时候那个孩子」。封面文案可以直接用第一章首题的 `intro` 回环呼应（数据里现成）。

### 1.3 视觉语言总则（同源约束）

- 只使用现有晨昏光谱色板（`:root` L13-23：paper/card/ink/yang/amber/yin/moon/cinnabar），**不新增体系外色**。
- 每章封面 = **一个主导色 + 一个点缀色**（不做橙蓝混合渐变，遵守 UI 方案原则 1「一次一色」）。
- 插画风格：**扁平剪影 + 渐变大色块**（storybook 感），几何元素克制，2-4 个主意象/幅。情绪靠「光线」传达，不靠表情细节。
- 所有装饰 SVG 加 `aria-hidden="true"`，场景语义同时由 emoji + 文字承载（无障碍兜底）。

## 二、章节封面设计（5 幕画面）

### 2.0 通用技术方案：`sceneArt(chNo)` 返回内联 SVG

**方案选型：内联 SVG 插画（主） + CSS 渐变底色（辅） + emoji 点缀（微）。**

理由（在零外部资源约束下对比）：

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| 纯 CSS 渐变 | 最轻、零代码量 | 只能表达氛围，无叙事画面 | 作底衬，不单用 |
| **内联 SVG 插画** | 可离线、可复用色板/`currentColor`、缩放不糊、手写可控 | 需要写几何代码 | **主方案** |
| emoji 组合 | 天然跨端、零成本 | 情绪弱、各平台渲染不一、显廉价 | 作题级小徽标与点缀 |

通用代码结构（新增函数，放在 `WHEEL_SVG` 一带的「纯展示资源」区 L2524 附近，与逻辑完全解耦）：

```js
/* [visual] 章节场景插画：5 幕光线 → 内联 SVG（零外部资源，几何+渐变） */
var SCENE_KEYS={1:'family',2:'school',3:'work',4:'love',5:'self'};
var SCENE_EMOJI={family:'🏡',school:'⛹️',work:'💼',love:'💞',self:'🌙'};
var CHAPTER_ART={ 1:'<svg class="scene-svg" viewBox="0 0 600 400" preserveAspectRatio="xMidYMid slice" aria-hidden="true">…壹章…</svg>', 2:'…', 3:'…', 4:'…', 5:'…' };

function sceneArt(chNo){
  var k=SCENE_KEYS[chNo]||'family';
  return '<div class="scene-frame scene-'+k+'">'
    + (CHAPTER_ART[chNo]||'')
    + '<div class="scene-shade"></div>'   // 底部柔光罩，让文字压图不刺眼
    + '</div>';
}
function sceneBadge(sceneKey){
  return '<span class="scene-badge scene-'+esc(sceneKey)+'">'
    + '<span class="sb-emoji">'+(SCENE_EMOJI[sceneKey]||'·')+'</span>'
    + '<span class="sb-name">'+esc({family:'家',school:'校园',work:'职场',love:'亲密',self:'独处'}[sceneKey]||sceneKey)+'</span>'
    + '</span>';
}
```

通用容器 CSS（新增，独立命名空间，不覆盖任何现有类）：

```css
/* ===== 测试页叙事视觉层（新增，命名空间 scene-/journey-/cover-）===== */
.scene-frame{position:relative;border-radius:var(--r);overflow:hidden;margin:0 0 14px;
  aspect-ratio:16/9;min-height:150px;}
.scene-frame .scene-svg{position:absolute;inset:0;width:100%;height:100%;}
.scene-shade{position:absolute;inset:0;background:linear-gradient(180deg,rgba(250,247,242,0) 52%,rgba(250,247,242,.42));}
/* 场景底色（SVG 未覆盖时的 fallback，兼作题级氛围带底色） */
.scene-family{background:linear-gradient(180deg,#FFF4E2,#F6C384);}
.scene-school{background:linear-gradient(180deg,#FFFDF6,#F5ECD8);}
.scene-work{background:linear-gradient(180deg,#EEF1F6,#D8E0EC);}
.scene-love{background:linear-gradient(180deg,#F6C384,#4E6E9E);}
.scene-self{background:linear-gradient(180deg,#232F45,#4E6E9E);}
/* 题级小徽标 */
.scene-badge{display:inline-flex;align-items:center;gap:6px;font-size:12px;letter-spacing:.14em;color:var(--fog);}
.sb-emoji{font-size:16px;line-height:1;}
```

> 约束提醒：内联 SVG 的 `id` 必须唯一（每章一个前缀，如 `c1sky`/`c2sky`），避免多章共屏时渐变 id 冲突。

### 5.2 风险与对策

1. **零外部资源红线**：所有视觉仅用内联 SVG / CSS 渐变 / emoji / 系统字体。对策：SVG 全部手写进 `CHAPTER_ART` 常量；禁止新增 `<img>`/`@font-face`/CDN；canvas 分享图继续只用 `_cxFont` 现有字体栈。
2. **不改题卷数据结构（P0/P1 硬约束）**：`scene`/`chapter`/`intro`/`kpLink`/`opts[].k` 全部是现成字段，映射表是「约定」而非「新数据」；唯一例外是 P2 的 `art` 种子字段（在方案内已标注为「**是**」）。
3. **移动端性能**：
   - 章节 SVG 只出现在**章节封面/回顾页**（每章 1 次渲染），题级只用渐变带 + emoji，避免 20 题 × 大 SVG；
   - `CHAPTER_ART` 用常量字符串（非每次拼接），5 幅 SVG 合计 <15KB 文本；
   - 动画只用 `opacity/transform`（走合成层），并加 `@media (prefers-reduced-motion:reduce){*{animation:none!important;transition:none!important;}}`。
4. **与《UI视觉优化方案_v1》兼容**：
   - 本方案新增类全部走独立命名空间（`scene-`/`journey-`/`review-`/`cover-`），不覆盖现有 `.q-opt`/`.ch-intro` 等规则（`.q-opt::after` 为新增伪元素，不冲突）；
   - 若 UI 方案先行落地 token 化，本方案 §二色值可直接换成语义变量（`var(--yang)` 等）；两者在 `:root` 与 `.q-opt` 处有交接点，建议**UI 方案先合、本方案后合**；
   - 极性印章 `.pol-yang/.pol-yin` 与结果页 `.ps-lbl-*` 刻意同色同构，属「有意的识别闭环」而非重复组件。
5. **`ch-head` 吸顶高度**：新增 `.journey` 行会加高吸顶区（现 L231 已 `padding:12px 20px 10px`）。对策：`.journey` 在 ≤640px 只显示 5 个 3px 节点条（隐藏 emoji），高度仅 +14px；如仍嫌高，可将 journey 并入 `progress-meta` 行内（flex 换行）。
6. **内容边界**：封面只画「场景」，不画题目内容（剧透会毁掉答题的自发反应）。第壹章小孩只给背影、第伍章人形用被子剪影，就是刻意「不剧透」。
7. **章节数耦合**：`journeyHtml` 硬编码 5 节点，用 `T.chapters.length` 兜底（小于 5 时只画实际章节数），防题卷扩展。
