## 二、问法修正原则（v2.2 用户指示：以《知识点切分总纲》为蓝本）

> **蓝本**：`2026-08-27-20-10-16\docs\阴阳人格_知识点切分_教材总纲_待确认.md`（197 知识点、阶0–9 十单元、y 编号体系）——用户此前已出过这稿总纲，问答卡的问法与体系以其为准。

1. **question = 总纲标题**：官方规范「**差异维度：阳X、阴Y**」（维度在前，阴阳特征在后）。示例：情绪表达：阳封存说没事、阴倾倒求接住（y1-07）｜能量流向：阳外耗、阴内耗（y1-08）｜充电方式：阳独自完成、阴被人看见（y1-11）｜边界感：阳铜墙铁壁、阴千疮百孔（y1-18）｜信任路径：阳砌砖墙、阴做试探（y1-12）｜控制目的：阳争夺定义权、阴掌控情绪（y1-16）｜攻击方式：阳一击毙命、阴反复拉扯（y1-13）｜仇恨路径：阳生戾气、阴积怨气（y1-20）｜战逃本能：阳战斗、阴逃跑（kp-a2）；
2. **kpId 对齐 y 编号**：每卡挂总纲的 y\* 编号 + 新增 `stage` 字段（0–5 阶数），前端按十单元「由浅入深」排序；
3. **insight 骨架 = 总纲「讲透」+「论点结构」字段**，V3.3 章节充实展开；总纲「源」列即 evidence 的语料锚点；
4. **卡片独立性**：不看测评、不知道自己型别，读一张卡即完整获得该知识点（是什么 → 阴阳各如何 → 机制根源 → 成长方向）；禁止「如果你的答案…」「测出…的你」等预设测评上下文的表述（shareText 同）；
5. **问题承诺=答案兑现**：一问一主题，主题内信息闭环；场景描述只允许出现在 evidence 原文佐证里；
6. 测评→卡片是单向链接（结果页按 kpLink 挂接），卡片不反向依赖测评。

## 三、含金量四查（每张卡自检）

| 查 | 标准 |
|---|---|
| ① 知识密度 | 盖住 evidence 只看 insight，用户能否获得完整可用的知识？不能=不合格 |
| ② 结构化 | insight 是否有公式/分类/对比/路径等「骨架」（不是流水句） |
| ③ 可溯性 | insight 的每个论断能在 V3.3 章节或已产卡找到出处（卡内用 kpId 锚点）；evidence 原文不改义 |
| ④ **阴阳成对**（v2.3 新增） | **每条 insight = 一个维度内的完整阴阳对照**：`维度引导词：阳<表现>；阴<表现>。`——禁止「阳一条/阴一条」分列割裂；条间=维度递进（现象→机制→信号→根源→判读）。示范：「充电方式：阳靠成就感与独处回流——做成一件事，能量就回流一格；阴靠被理解与被看见回血——被一个在乎的人认真倾听，胜过独自休息。」 |
| ⑤ **职责边界**（v2.4 新增） | 知识卡的职责 = **呈现「阴阳维度的区分点」**，不做判定教学——禁止「有不配得就是阴」「看 X 就知 Y」类单点判定式表述（经验信号只能作「参考信号」且注明非判据，与 y0-03「判断没有标准」口径一致）；判定是测一测的职责，区分维度卡收尾可引导「想确认自己偏哪边？去『测一测』」（此为卡片与测评的唯一接口） |
